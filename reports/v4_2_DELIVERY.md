## Проверка

Библиотека → импорт своего трека; Структура → фаза → Добавить → библиотека, дважды нажать один трек; play не добавляет. Добавить паузу → повернуть минуты/секунды → применить; долгим удержанием строки/захвата изменить порядок. Сохранить шаблон, перезапустить. Записать личный трек категории Установки, прослушать/сохранить, найти Мои + Установки. Начать → кольцевая перемотка/кнопки часов → Закончить сейчас → Прервана в Истории; полное проигрывание → Завершена.
