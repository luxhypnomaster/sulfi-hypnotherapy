# №17 — приёмка на двух телефонах

**Все физические пункты пока NOT_RUN.** Эмулятор и скачанные APK проверены; это не физическая приёмка.

[MASTER27](https://github.com/luxhypnomaster/sulfi-hypnotherapy/releases/download/untagged-c7073f0a5871b5fb707c/master27.apk) · [CLIENT27](https://github.com/luxhypnomaster/sulfi-hypnotherapy/releases/download/untagged-c7073f0a5871b5fb707c/client27.apk) · [Страница пары](https://github.com/luxhypnomaster/sulfi-hypnotherapy/releases/tag/untagged-c7073f0a5871b5fb707c). Версия 0.4.19+27, source `fbdaa7b0b51f9b742a0c5db84f5ef50ba4375568`. Открыть Chrome и войти в GitHub владельца. Частная ссылка без входа может возвращать404. Скачать нужный APK, не ZIP исходников и не служебный JSON. CLIENT можно передать на второй телефон через Quick Share: доступ к исходникам и токены не нужны.

1. В Android → Настройки → Приложения проверить установленную версию. Native-проверены MASTER25/26→27 и CLIENT25→27; остальные пути не объявлены проверенными.
2. Установить APK обычным обновлением соответствующего пакета. При конфликте остановиться и записать текст ошибки. Не удалять приложение, не очищать данные, не понижать версию. Проверить прежние треки, модули, программы, текущую конфигурацию, историю и черновики до Google-входа. Native-проверка не является резервной копией личных записей.
3. В «Вашем пространстве» проверить фактическую версию27. MASTER — Google владельца, CLIENT — другой реальный аккаунт. Проверить роль, подтверждённую сервером. Дневник → каталог → главная; холодный перезапуск; повтор через15/30/60мин. Записать неожиданные picker, ошибки и состояния очереди.
4. Отдельно опубликовать в каталоге модуль «Индукция Элмана» из трёх собственных треков; дождаться серверного подтверждения. Затем программу с сохранением template IDs. Каталог не должен сам создавать запись дневника. Создать отдельный анонс с ContentLink точной опубликованной ревизии. Старое «Добавь себе в библиотеку» — авторский текст, не кнопка.
5. На CLIENT установить выбранные зависимости, повторить установку и проверить отсутствие новых дублей. Отключить сеть и реально прослушать три трека. Native AudioTrack не доказывает слышимость на телефоне.
6. Проверить lifecycle pause → Resume, выключение/возврат сети, ручную паузу и cancel. Cancel не снимает публикацию. Logout → перезапуск: автоматического входа и отправки быть не должно. Явный вход тем же owner → Resume; другой owner не должен получать прежнюю приватную очередь.
7. При проблеме включить QA trace, воспроизвести один раз и скопировать санитизированный trace. Не присылать пароль, OAuth token или credential. Базу не очищать.

Известное ограничение GAS6: title+short message без blocks пока отклоняется. Патч не разрешён и не развёрнут. Не смешивать этот серверный отказ с ошибкой Google-входа. Испытание такого поста отложено до отдельного согласованного серверного этапа.
