# CHANGES №21

Source `8546bc66137bc7796954cd04f0b65cdc2851c416`, base PR51 `a7c29a7b478b6c3b001d70d3158b4a65d57b3c50`. Draft PR52: https://github.com/luxhypnomaster/sulfi-hypnotherapy/pull/52 . Все PR48–51 остаются необъединёнными; это stacked diff, не перенос в main.

1. **Исполняемый sandbox.** Новые experimental `sqlite_snapshot_store.cjs` и `metadata_runtime.cjs`: реальные SQLite/WAL/FULL, immutable triggers, prepared readback, transaction CAS+HEAD+receipt, process-kill rollback, повтор после потерянного ответа, scope epoch/expiry. Старый Task20 snapshot prototype расширен совместимо: отдельный config stream, строго публичная card projection. Production Router/build source не подключает эти файлы.
2. **Runtime MASTER/CLIENT.** `metadata_gateway.dart` проверяет version/schema/canonical/SHA/nonce/server binding/scope/expiry/atomic capability; `metadata_runtime.dart` связывает транспорт, SQLite lastGood, настройки и существующую queue18. Общий `SessionController` создаёт тот же runtime в UI и headless executor. Флаг `SULFI_METADATA_V1` по умолчанию false; старый nullable transport сохранён для прежних контрактных тестов.
3. **Существующая очередь.** Lightweight catalog intent имеет приоритет только перед ожидающими файлами; активная передача, её owner/checkpoint и native scheduler не прерываются. Новые подписи стадий не называют metadata установленным аудиофайлом. Equal HEAD не загружает snapshot. Ошибка capability временно ограничивает повтор на20сек, а не блокирует его навсегда; 401/403 не вызывают account chooser.
4. **Каталог/витрина.** AlchemistStoreScreen читает проверенный локальный snapshot, показывает capability status и сохраняет legacy catalog.list fallback. Настройки имеют отдельные local saved, server applied и собственную подтверждённую receipt. Applied refresh не заменяет receipt. После потерянного COMMIT ответa cold store повторяет исходный request/CAS; более новая appliedRevision другого автора не откатывается.
5. **Статичный выбранный preview.** Кнопка «В баннере главной» в текущем DiaryEditor открывает существующий HomeComposition и общий renderer DiaryPublicationSlide с выбранным несохранённым draft. Автосохранение при этом не запускается; carousel/read-state/player/network не включаются. Геометрия header/board/navigation та же; прежний полный reader preview сохранён.

Schema9, template IDs, файлы, library/history/diary/outbox и settings20 namespace сохранены. Код native, OAuth, Auth19, package IDs/versionCode/signing, GAS6 и main не менялись. Новый provider, quota UI, backup service и role governance не создавались.
