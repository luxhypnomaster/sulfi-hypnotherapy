# №16-Б — приёмка с телефона

Дата: 12.11.2026. Ветка: `fix/task16b-auth-transfer-publication`. Кандидат приложения: `012f7f69b7ad99c0d44f2a442d9649aa1481117e`. Draft PR: https://github.com/luxhypnomaster/sulfi-hypnotherapy/pull/45 . Продолжение №16/16-А, не №17.

Сначала владелец скачивает MASTER APK25 из закрытого GitHub draft (ссылка и SHA в APK_INFO_16B.md), войдя в GitHub в том же браузере. Установить поверх MASTER24, не удалять старое приложение и не очищать данные. CLIENT APK — отдельный package на втором телефоне; при отсутствии доступа к private draft передать скачанный файл через Quick Share. Исходники/токены/доступ к репозиторию передавать не нужно.

1. Проверить четыре личных трека/свои шаблоны/историю/дневниковые черновики после обновления. При конфликте установки остановиться и прислать точный текст, не удалять старую APK.
2. Войти MASTER и CLIENT реальными Google-пользователями; сравнить состояние «человечка» и щита. Закрыть/открыть приложение. Проверить повторный запрос после истечения токена. Ни пароль, ни ID token присылать не надо.
3. MASTER: модуль «Индукция Элмана вариант 2», три трека → «Добавить в каталог». Сохранить название/аннотацию/описание/категории/обложку; явно выбрать видимость для читателей. Начать загрузку, перейти в библиотеку: очередь остаётся доступной.
4. Проверить паузу/продолжение, отключение сети и возврат. При сворачивании ожидается кооперативная пауза; после возвращения продолжить явно. Сравнить 100% bytes и отдельное подтверждение сервера. При сбое записать безопасный код/traceId, тип сети и время.
5. «Подготовить к публикации» → дневниковый анонс exact версии; при ошибке каталога он должен остаться draft. Повторный анонс не должен передавать три аудиофайла повторно. Обычный preview открывается tap по записи.
6. CLIENT: открыть анонс → ContentLink → выборочная установка модуля и трёх зависимостей; повторить установку и проверить отсутствие дублей.
7. Включить авиарежим; выполнить сессию с реальным звуком всех трёх треков, паузами, выходом и заблокированным экраном. Зафиксировать фактический результат и длительность.
8. Повторить на Wi-Fi/mobile и при переключении в середине передачи; logout во время задачи должен остановить доступ, не удалить файлы. Не пытаться обходить Google OAuth Testing.

Новый backend diagnostic deploy не обязателен для первой проверки APK25 на совместимом GAS6. Для проверки новых server error codes/trace response требуется отдельное разрешение на кандидатный deployment. Физическая приёмка APK25 пока NOT_RUN; прежние начальные входы APK24 OWNER-REPORTED PASS не отменяются и не означают полный E2E.
