# №24 — будущая комплексная приёмка

**Сейчас ничего устанавливать не требуется.** Новых APK/AAB/Gradle/эмуляторов/телефонных испытаний №24 нет. Ни один результат Flutter Navigator не назван Android/Google PASS.

После review неслитой цепочки PR52→54→55→56 и отдельного разрешения на будущую сборку:

1. Провести общий gate №23: прежние package/signing, возрастающий versionCode, сохранность SQLite/sidecars/медиа/истории/черновиков/капсул/очередей при обычном обновлении. Без uninstall/clear/downgrade. UX24 этот gate не заменяет.
2. На MASTER и CLIENT открыть очередь из разных разделов, нажать глобальные «Передачи»10раз, проверить один экран и один системный/UI Back. Повторить открытие из уведомления и из фокусированного редактором задания; существующая задача/receipt/пауза не меняются. Открытый несохранённый диалог поверх очереди не закрывается автоматически.
3. Открыть конкретную публикацию из Home. Отдельно перелистать страницы, затем10публикаций. Back возвращает к контексту входа. «К списку» не образует Reader→Journal→Reader петлю. После фильтра журнала post1→post10→post11 не выходит за выборку; фильтр/позиция родителя сохраняются. Не появляются чужие/снятые/истёкшие записи; переход не объявляет чтение завершённым.
4. Проверить настоящее внешнее открытие и Android gesture/cold restart, а не только root Widget fallback. Войти двумя реальными аккаунтами по прежней авторизации, убедиться, что навигация не вызывает лишний picker. Отказ/ожидание auth не удаляет локальные материалы.
5. Вставить два одинаково названных модуля и личный fork. Изменить только A, сверить отдельную жёлтую метку/фуксиевый курсив, вернуть исходный состав — метка исчезает. В активном плеере остаются прежние playback colours, жёлтый таймер и настоящая вложенность.
6. Завершить реальную сессию, из истории одним «На главную страницу» вернуться к Home без запуска повтора/активного RunScreen. История и её заметки остаются. Обычная стрелка Back имеет прежний смысл.
7. Проверить общий щит из Home и библиотеки в обоих изданиях; CLIENT UI не выдаёт серверных авторских прав. Без Google/сеть-offline открыть/создать/сохранить локальный MASTER-черновик. Наличие кнопки входа не должно превращаться в обязательный шаг локального редактора.

Визуальная приёмка: 9:16, малый экран и увеличенный шрифт, настоящие Android safe areas, доступность жестов/клавиатуры.
