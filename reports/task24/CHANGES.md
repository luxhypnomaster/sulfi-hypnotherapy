## Исправлено по регрессионным тестам

| Сценарий | До | После |
|---|---|---|
| Десять нажатий глобального индикатора очереди | 11 маршрутов вместе с родителем, повторные Back | Одна очередь в данном Navigator; Back возвращает к исходному родителю |
| Индикатор при очереди, открытой из редактора/каталога | Новый экземпляр вместо текущего | Распознаёт прежний route и сохраняет focusName/фильтр/задачу |
| Индикатор над модальным редактором | Риск размножить очередь или потерять контекст при popUntil | Ничего не разворачивает принудительно; несохранённый текст и настоящий многошаговый Back остаются |
| «К списку записей» из читателя, открытого с Home | Home→Reader→Journal, Back снова Reader | Reader заменяется журналом; Back ведёт к Home |
| Последовательные публикации | Самостоятельных prev/next-post не было | Отдельные кнопки «Предыдущая запись / Следующая запись», pushReplacement без цепочки sibling routes |
| Журнал с фильтром/сортировкой | Первоначальный прототип переходил от post1 к post2 вне фильтра | Передаётся список IDs видимой выборки; post1→post10→post11 для поиска post-1; родительский журнал и ввод сохраняются |
| Корневой reader/deep-link контекст | Back не имел логического родителя | Определённый fallback в существующий журнал; Home при наличии SessionScope открывает настоящий HomeScreen |
| Десять быстрых тапов по прежней домашней публикации | 11 routes | Дубли того же опубликованного viewer/владельца/контекста объединяются в слое читателя |

При переходе между публикациями сохраняется контекст открытия, приостанавливается предпрослушивание, заново проверяется текущая видимость после await. Не выбираются чужие, снятые, закрытые или истёкшие публикации. Переход сам по себе не помечает запись прочитанной. Preview, calculateOnly и publicationReview не участвуют в устранении дублей, поэтому редакторские/проверочные потоки не удаляются. Внутренняя пагинация записи остаётся прежней и независимой.

Устранено синхронное `setState during build`: исходящий reader получает безопасное обновление после кадра, если новый журнал синхронно сообщает о sync из initState. Новые кнопки используют прежний Roboto; на рендерах исправлено отображение кириллицы. Авторизация и передача не запускаются навигационными callback.

- `lib/ui/alchemist_queue_indicator.dart`: оба входа badge/native-status используют один idempotent opener.
