## Приёмка на телефоне

1. В установленной версии №4 сохранить внешнюю ZIP-капсулу через Библиотека → щит → резервная копия. Установить APK №5 поверх №4, не удаляя приложение. При конфликте остановиться и открыть диагностику сертификата; не обходить ошибку удалением данных.
2. Дневник: текст + картинка → Аудио → Записать → 10–15 секунд → Добавить в дневник с пустым именем. Прослушать в читателе и после перезапуска. Проверить ретейк, отмену, импорт файла и restore капсулы; в библиотеке не должно быть этого вложения.
3. В Авторе импортировать файл в Общие, затем переключиться в Клиента: файл остаётся в Общих, используется в сессии, но не редактируется/удаляется. Создать личные аудио, модуль, шаблон и запись дневника, проверить сохранение. Вернуться в Автора без потери данных.
4. Завершить сеанс естественно, потом отдельный прервать. Каждый раз открывается своя карточка. План сразу раскрыт; заметка сохраняется отдельно; Back ведёт в список. Проверить паузу, переход/seek к концу и незавершённые элементы.
5. В карточке: повтор с новым номером; изменённый/удалённый шаблон; отсутствующее/изменённое аудио с явной пересборкой. «В редактор» не запускает звук, отмена сохраняет текущий план, сохранение нового шаблона не меняет старый.

Команды для разработчика: `flutter pub get --enforce-lockfile`, `dart format --output=none --set-exit-if-changed lib test`, `flutter analyze --fatal-infos`, `flutter test --reporter expanded`, `flutter test test/task5_client_build_test.dart --dart-define=SULFI_EDITION=client`, `node --test server/google_apps_script/test/backend.test.mjs`, `flutter build apk --debug`.
