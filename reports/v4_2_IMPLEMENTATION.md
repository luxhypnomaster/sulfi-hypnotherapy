# Реализация v4.2 — 0.4.2+7

Ветка `feature/v42-corrections-diary`, база v4.1 f96b84f, без изменений main/develop. Требования из `docs/v42/` приоритетнее старых указаний, включая отмену запрета дневника.

## Данные и совместимость

SQLite v4 **только добавляет** три таблицы дневника: public cache, author drafts и sync revision. Аудиометаданные/байты, определения модулей, текущая конфигурация, шаблоны, frozen runs и actual events не пересоздаются. Проверка v3→v4 сравнивает все прежние строки и байты файла; сохранены тесты миграций v1/v2. Новые категории добавлены по строковому ID, не ordinal. `recorded`/личный раздел независимы от категории Установки; записанный файл нельзя перевести в Общие через редактор метаданных.

Silence/FreeWork остаются внутренними видами для совместимости, в новом UI — одна Пауза. Нулевой самостоятельный интервал имеет duration=0, а не null/60; legacy null поддерживает ручное завершение. Задержка перед элементом остаётся отдельным полем (шаг 5 секунд), самостоятельная пауза редактируется с точностью до секунды. Расчёт не складывает её дважды. ID и снимки исполнения не меняются при редактировании текущего экземпляра.

## Рабочие экраны

- Выбор аудио: ~52 dp, тап добавляет occurrence и оставляет каталог открытым, повтор разрешён; отдельный play, поиск, Все/Общие/Мои + категории, маленький импорт. Управление файлами сохранено отдельно.
- Структура: один прокручиваемый reorder-список для всех уровней, без вложенных scroll views. Long-press по строкам, у фаз/модулей удобный захват слева. Фазы и элементы переставляются в рамках своего уровня; перенос между фазами/модулями остаётся в контекстном меню. Автопрокрутка поддерживается стандартным ReorderableListView. Раскрытие +/− всегда на месте, меню отдельно внутри раскрытой области. По одному Добавить с меню. Закреплены ровно Выбрать / Сохранить / Применить; применение не запускает сеанс.
- Редактор определения модуля: треки/паузы перемещаются в едином порядке и сохраняются в каталоге; уже вставленные экземпляры не переписываются.
- Новая пауза и задержка перед треком используют один утверждённый золотой арт с глазом, реальные цифровые поля и две вертикальные крутилки с haptic detents. Значения из примера PNG маскируются во время Flutter-paint; файл референса не редактируется. Сохранение/отмена и сброс настоящие, описание не запрашивается.
- Шаблоны — плотные строки, выбор одним тапом с защитой изменённого черновика, контекстные действия сохранены. Диктофон поднят, декор сокращён, теги/назначение модуля раскрываются отдельно; действия сохранения закреплены. Дубль <1 секунды подписан явно, пустой файл по-прежнему отвергает декодер.
- Главная: компактные номер/дата, двухстрочная тема с редактированием, короткое послание/переход в дневник, прежние четыре нижних действия.

## Плеер

Сохранён единственный утверждённый PLAYER_FINAL_APPROVED_9x16: исходные орнаменты/золото/змея/огонь/глаз используются как декор, текст и управление — Flutter. Колба имеет полноценную ширину; убывающий уровень вычисляется по forecast всего исполнения. Слева только шкала прокручивается, активная фаза раскрывается, имена неактивных фаз/модулей остаются. Часы содержат предыдущий/следующий трек, Play/Pause, время, живое кольцо и circular seek по углу; в интервале seek не отправляется. Три дополнительные пары навигации сохраняют сервисную защиту двойного нажатия и единый Run.

Кнопка #A6FF2E «Закончить сеанс». Подтверждение позволяет выйти либо закончить сейчас; безопасный выход не помечается завершённым заранее. Реальный конец/прерывание сохраняет события и автоматически открывает Историю с выделенной записью. Проверено через настоящий Home → Run → History, а не только вызовами репозитория. Закрытие диалога дожидается завершения route animation; UI не закрывает случайно чужое окно при финальном событии.

## Дневник

Это авторские публикации Сульфи, не личный дневник клиента. Оглавление опубликованного, пустое/ошибка/офлайн/обновление, кеш. Читатель и предпросмотр используют один виджет; пагинация по TextPainter/доступной высоте/масштабу, Unicode и слова сохраняются; дата/полный день недели/ID/послание только на первой странице. Кожа/зажим/перо из существующего материала, бумага и знак серы с ouroboros нарисованы виджетами, без нового постера.

Авторское рабочее место отдельно включается конфигурацией сборки; в обычной сборке нет авторских кнопок и доступа к drafts. Редактор автосохраняет два поля, сохраняет при закрытии/уходе в фон, даёт точный предпросмотр. Для публикации требуется проверенный сервером временный токен, хранящийся только в памяти. Публичный клиент получает только published feed; страницы сохраняются атомарно, снятия приходят по ID, авторские черновики остаются. Личная аудиотека/история не отправляются. [Контракт и настройка](../docs/v42/DIARY_BACKEND_RU.md).

**BLOCKED:** нет действительного backend URL/инфраструктуры и авторского входа для живой публикации. APK не содержит вымышленных контактов облака, токенов и демонстрационных «публичных» записей. До настройки каталог будет пуст. Тестовый сервер используется исключительно в тестах.

## Проверка на телефоне

1. Устанавливать совместимо подписанный APK поверх имеющегося приложения; при конфликте подписи **не удалять приложение с личными файлами**. Постоянный ключ пока не настроен, бесшовное обновление на телефоне не проверено.
2. Импортировать два несекретных трека; в конструкторе открыть Добавить → библиотека, тапнуть один трек дважды. Каталог остаётся, play не добавляет.
3. Создать паузу, повернуть минуты и секунды отдельно, применить; снова открыть, обнулить. Долгим удержанием строки/захвата переставить паузу/модуль/фазу; выйти и перезапустить.
4. Создать личную запись категории Установки; завершить, прослушать и сохранить. Проверить Мои + фильтр Установки и добавление в любую фазу.
5. В плеере проверить кольцевую перемотку и три кнопки на часах; затем трек/модуль/фазу, сохранение паузы и текущего Run. Закончить сейчас → Прервана в Истории; доиграть всё → Завершена.
6. Проверить слышимый звук и интервалы при блокировке, звонке, отключении гарнитуры/Bluetooth; тактильность колёсиков и большой системный шрифт.
7. Открыть дневник на главной. При отсутствии сервера должно быть честное пустое/ненастроенное состояние; после настоящего подключения опубликованное читать офлайн. Авторский редактор проверять отдельной авторской конфигурацией.

Физического Android/эмулятора нет. Native mic, фон/блокировка, звонки/Bluetooth, vibration feel, установка/подпись и реальное обновление базы телефона — **NOT TESTED**. Автотесты внедряют захват/транспорт и не доказывают слышимость звука на Samsung.
