# №16/16-А — точная проверка двух APK24 с Android

**Первый обязательный шаг человека — Google-вход владельца в мастерской APK.** Компьютер, повторный clasp-login, пароль/токен в чате не требуются.

## Скачать и установить

- [Мастерская APK24](https://github.com/luxhypnomaster/sulfi-hypnotherapy/releases/download/untagged-9962b11f7ce0aa819785/sulfi-master-test-24.apk) — поверх прежней «Сульфи» на телефоне1.
- [Клиентская APK24](https://github.com/luxhypnomaster/sulfi-hypnotherapy/releases/download/untagged-9962b11f7ce0aa819785/sulfi-client-test-24.apk) — отдельное приложение на телефоне2.
- [Страница обеих сборок в GitHub](https://github.com/luxhypnomaster/sulfi-hypnotherapy/releases/tag/untagged-9962b11f7ce0aa819785). Репозиторий приватный: для скачивания со страницы нужен вход владельца в GitHub.

Тестировщику не нужен доступ к репозиторию: скачайте клиентский APK на своём Android и отправьте именно файл через системное «Поделиться»/Quick Share/Bluetooth на второй телефон. Не передавайте пароль GitHub или Google. Не загружайте APK на Google Drive. Это две тестовые сборки, не объявленная принятой поставка.

Каждая APK около185MiB. Скачивать ZIP, исходники, служебные файлы не нужно. При разрешении установки Android выбирайте источник, из которого скачан APK. При конфликте пакета/подписи остановитесь: **не удаляйте прежнее приложение и аудио**. Подпись и package сохранены и проверены, реальное обновление на телефоне ещё NOT_RUN.

## 1. Владелец / MASTER

1. В мастерской APK откройте «Дневник» → значок «Подключение и права» → «Войти через Google».
2. Выберите Google-аккаунт владельца. Ожидается роль «Мастер», подтверждённая сервером.
3. Нажмите «Проверить права на сервере». Она создаёт/закрывает только собственную ограниченную техническую публикацию. Ожидается успешная проверка разрешения публикации.
4. Сообщите текст результата. При Google-ошибке пришлите текст и безопасный код SDK; email/токены закройте. Клиентские email в test users не добавляйте. Если Google блокирует вход, дальнейший сценарий приостанавливается для точной диагностики.

## 2. Второй аккаунт / CLIENT

1. На телефоне2 откройте клиентскую APK → «Дневник» → «Подключение и права» → Google-вход **другим** аккаунтом.
2. Ожидается «Клиент». «Проверить права на сервере» должна подтвердить отказ публикации. Авторские редакторы не должны открываться.
3. Не проверяйте клиента аккаунтом владельца: сервер сохраняет роль MASTER независимо от типа APK. Для контроля можно войти другим аккаунтом в мастерской APK — он обязан остаться CLIENT.

## 3. Три реальных трека → каталог → дневник

1. Телефон1: «Шаблоны и модули» → «Модули» → «Создать модуль». Название «Индукция Элмана»; добавьте3 настоящих своих трека из библиотеки в нужном порядке; сохраните.
2. Меню модуля ⋮ → «Подготовить к публикации». Заполните аннотацию и выберите общедоступную видимость (public); нажмите «Опубликовать». Дождитесь подтверждения сервера и завершения передачи. Личная библиотека сама не публикуется.
3. «Дневник» → «Новая запись»: название, короткий текст → «Добавить из каталога» → опубликованный модуль «Индукция Элмана». Опубликуйте запись. Ссылка должна быть exact ContentLink, не аудиосообщением/локальным путём.

## 4. Клиентская установка и офлайн

1. Телефон2: обновите дневник, откройте карточку модуля → «Посмотреть / установить» → «Установить». Проверьте состав: модуль и3 нужных трека, порядок/паузы совпадают.
2. Повторите установку: идентичные файлы не должны скачиваться повторно. Личные материалы не должны заменяться автоматически.
3. Выключите сеть. Используйте модуль в сессии, запустите воспроизведение всех3треков; проверьте звук и работу при блокировке экрана.
4. Сделайте личную копию модуля с другим названием/паузой. Оригинал и копия должны остаться отдельными. Экспортируйте свою копию локально, без облачной публикации.
5. Перезапустите приложение, выйдите/войдите, убедитесь в сохранности библиотеки и правильной роли. Google token не хранится в SQLite; после перезапуска облачные авторские функции требуют входа. Приватные авторские черновики не должны появиться у клиента.
6. После отдельного подтверждения владельца можно снять каталоговую публикацию: новая установка недоступна, принятая офлайн-копия сохраняется.

## Что сообщить

MASTER-вход/проверка; CLIENT-вход/отказ публикации; опубликованный модуль3треков; дневниковая ссылка; установка; офлайн-звук; обновление без потери данных; logout/restart; сообщение ошибки при наличии. Отдельно секунды: вход, публикация, открытие каталога, загрузка3треков, офлайн-старт. Не использовать51:42 прежнего CI как время скачивания.
