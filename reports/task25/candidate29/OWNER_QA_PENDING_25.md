# APK29: условия физической приёмки (пока НЕ разрешение на установку)

На момент подготовки этого документа кандидатные APK ещё не выданы. Ссылка на карантинный артефакт не является рекомендацией установить его. Итоговый RESULT должен отдельно подтвердить реальные SHA/signature/package/version и native28→29 для MASTER и CLIENT.

После фактического PASS: кандидатная версия0.4.21+29 сохраняет applicationId MASTER ru.sulfi.sulfi_hypnotherapy и CLIENT ru.sulfi.sulfi_hypnotherapy.clienttest, прежний сертификат0b7435682d27200e630d5837d40457fa64e905d8c43c4ea692c7e1a2d810afc6. Это подписанные debug-кандидаты для согласованной приёмки, не production-релиз.

Перед установкой владелец отдельно разрешает тест на своём телефоне и проверяет текущую версию. Доказанный сценарий будет указан в RESULT; code29 подходит только поверх меньшего code и совпадающей подписи. При конфликте пакета/подписи или требовании удаления — остановиться, ничего не удалять, не очищать данные и не понижать версию. Сохранить личную резервную капсулу через приложение, не загружать личные материалы в отчёты.

Записать до/после количество и названия нескольких аудио, модулей/программ, истории и локальных черновиков, выбранные настройки. Установить именно свою редакцию штатным обновлением. Проверить после холодного запуска те же материалы и воспроизведение офлайн. Google-вход, реальная передача, блокировка экрана/энергосбережение и MASTER→CLIENT на двух телефонах — отдельная физическая приёмка; автоматический эмулятор их не доказывает.

Историческая причина исчезновения материалов24→25 остаётся UNKNOWN. Ни один тест не обращается к телефону владельца или его единственной базе. Код20–25 остаётся в draft PR57; main получает только узкие инструменты сборки через обычные PR59/60. GAS6, production-gate, OAuth, ACL, signing-key и данные не изменяются.
