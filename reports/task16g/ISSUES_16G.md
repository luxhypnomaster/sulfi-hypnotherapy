# №16-Г — оставшиеся ограничения

1. **Реальные Google/Drive/два телефона: NOT_RUN.** Вход MASTER/CLIENT, live публикация и офлайн-слышимость требуют настоящих пользователей. Controlled contract тесты подтверждают код, но не заменяют физическую приёмку. Точные шаги без ПК — OWNER_PHONE_QA_16G.md; выполнять установку только при выданном кандидате и решении владельца.
2. **Выдача APK зависит от native safety gate.** Подписанная сборка сама по себе не разрешает распространение. До доказанного сохранения UI-created графа APK25→26, cold restart и отрицательных bootstrap-проверок пара закрыта в CI-кэше. Фактическое решение и ссылки — RESULT_16G.md. Подробные инфраструктурные и UI-driver неудачи сохранены в CODEX_EFFICIENCY, без ложных PASS.
3. **GAS6 не изменялся.** Серверный диагностический candidate из №16-Б остаётся без deploy. Если понадобится именно его rollout — отдельное согласование после reviewed diff/rollout/rollback. Новый сервер, старый дневник, ACL и OAuth settings не изменялись.
4. **Ранее пропавшие тестовые объекты не восстанавливаются.** Это новое решение владельца из №16-Г; прежний root cause №16-В остаётся UNKNOWN. Никакого ADB/forensic/очистки/импорта на телефоне владельца не выполнялось и не требуется для продолжения.
5. **Отключён опасный автоматический orphan cleanup.** Неопределённые/частичные файлы сохраняются, поэтому возможен рост занятого места. Автоматический GC не возвращать ради экономии диска без отдельного доказательства неиспользуемости.
6. **Горячий rollback journal может безопасно блокировать bootstrap.** Preflight не чинит исходник и не удаляет sidecars; при неоднозначности показывает ошибку вместо пустой библиотеки. Автоматическое восстановление всех видов повреждения не заявляется. Не обходить защиту удалением приложения/данных.
7. **Разные байты при одном logical ID** по-прежнему отклоняются существующим storage. Для других байтов нужен новый ID; экспериментальная revision-миграция PR43 не объединялась.
8. **Приватный GitHub draft не является публичной ссылкой.** Скачать может авторизованный владелец/участник репозитория. При допустимой выдаче владелец может передать скачанную APK тестировщику через Quick Share. Репозиторий/релизы не открывались; APK на Google Drive не загружались.

Не закрывать №16/16-А по одним автоматическим тестам. Дневниковые авторизованные drafts, настоящий SDK и сетевой переход — обязательный остаток физической приёмки. Ни новой №17, ни нового сервера не создавалось.
