# Авторский дневник внутри приложения — 04.11.2026

Ветка `feature/diary-in-app-publishing`, исходная точка `0e35890` (проверенная v4.2),
версия 0.4.3+8. main/develop не изменяются. Это следующий изолированный этап.

В v4.2 были авторские черновики/кеш/редактор, но требовались отдельный build flag
и ручная вставка токена; реального входа/сервера не было. По требованию владельца
все авторские действия теперь предусмотрены в одном приложении.

Реализованы SDK `google_sign_in:7.2.0`, вход из оглавления, скрытие авторского UI
до входа владельца, независимые местный режим и серверное право публикации.
Ручное поле токена удалено. Выход не удаляет черновики, после перезапуска нужен
новый вход. Сохранение на Диск явное; загрузка добавляет отсутствующие ID без
замены местных правок. Во время записи поля и повторные действия заблокированы.

Подготовлены Apps Script транспорт/сервер: настоящая RSA-проверка ID token,
закрытый Drive store, отдельные публичные снимки, optimistic versions, lock,
пагинация/ревизии/tombstones. Сохранение правок не обновляет публикацию.
[Конфигурация, контракт и лимиты](../docs/v42/DIARY_BACKEND_RU.md).

SQLite остаётся v4, миграции/сброса нет. Аудио, каталог, конфигурация, шаблоны,
история и старые черновики сохраняются. applicationId и подпись не менялись.
Эти личные данные не входят в облачные запросы дневника.

Фактический Google-доступ: экспорт указанного Apps Script проекта прочитан через
подключённый Drive. В нём только manifest и стандартная `myFunction`. Резервная
копия вне Git: `/workspace/artifacts/drive-diary/apps-script-before.json`.
Проект переименован через Drive в «Сульфи — дневник». Это подтверждает чтение и
изменение названия. Изменение исходников, OAuth-настройки и deployment НЕ выполнялись:
инструментов управления Apps Script и выданной им OAuth-авторизации нет.
Включённая настройка API такой доступ автоматически не даёт. Ранее подготовленные
папка/пустой каталог закрыты; статьи и общедоступный write endpoint не создавались.

Осталось / не проверено:

- **BLOCKED:** реальные OAuth Web/Android clients, SHA-1 стабильной подписи,
  Consent Screen, авторизованное управление Apps Script, `/exec` deployment.
  APK без этих настроек сообщает об их отсутствии, успешный вход не имитируется.
- Нет физического Android: native Google chooser/consent, живые Drive permissions,
  публикации/квоты/второй телефон, слышимый звук/микрофон/фон и обновление подписи
  не проверены.
- Отдельный UI сравнения существующих конфликтующих версий ещё не реализован;
  загрузка сохраняет все местные тексты. MVP store ограничен 2 MB.

После настройки: открыть дневник без входа → нет черновиков/редактора. Войти
владельцем → создать/закрыть/открыть → текст сохранён. Сохранить на Диск → читателю
ещё не видно. Опубликовать → обновить второй телефон → статья видна. Изменить
черновик → читатель видит старую публикацию. Опубликовать снова → видит правки.
Снять → после синхронизации статья исчезла, авторский текст цел. Выйти → черновики
скрыты и не удалены. Чужой Google-аккаунт редактор не открывает.
