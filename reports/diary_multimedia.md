# Мультимедийный дневник — аудит и выполнение

База: `06207e4`, ветка `feat/sulfi-multimedia-diary`. Рабочее дерево до начала чистое. Пакет редакции 1.1 получен с Диска, ZIP проверен. Правки ограничены дневником и его точкой входа.

Исходные разрывы: запись содержит только message/body, нет заголовка, блоков, медиа, ручного порядка, удаления; читатель на светлой бумаге расходится с каноном. Текстовый редактор сохраняет локальные черновики, серверная публикация имеет проверку Google JWT/версий. Эти механизмы и SQLite v4 сохраняются. Данные сессий, шаблоны, библиотечные аудио и часы не мигрируют.

Read-only аудит 4 ноября: существующий JSON-каталог 79 байт, приватный; Apps Script `10jrwAx…Va0` существует, имя метаданных «Сульфи — дневник», shared=true. Следовательно, пакетный аудит об отсутствии scriptId уточнён. URL deployment и Google OAuth client ID в конфигурации отсутствуют. Среда не имеет Google API identity; Drive connector не предоставляет API управления исходниками/deployments Apps Script. Живая публикация/доставка медиа BLOCKED. Новый каталог, папки и скрипт не создаются, публичность не меняется. Артефакты приложения на Google Диск не загружаются.

## Реализованный локальный этап

Модель v2 добавляет title/order и стабильные text/image/audio-блоки. Старый body остаётся совместимым представлением: старые JSON превращаются в один текстовый блок с прежним содержимым. Номера при перестановке не меняются; неподтверждённые локальные черновики могут оставаться без номера. Первая страница показывает дату создания в местном времени, в данных даты UTC.

Редактор содержит одно прокручиваемое дерево блоков с отдельными рукоятками, командами Выше/Ниже, удалением с Undo, заменой файла и редактированием подписи/alt/названия аудио. Послание растёт до четырёх видимых строк, затем прокручивается внутри; ограничения в четыре строки или 1000 символов нет. Локальный debounce 350 мс сериализует сохранения; явное сохранение/выход ждёт результата. Ошибка оставляет текст на экране. Для защиты от слишком больших/испорченных JSON локальный текстовый размер ограничен 1 млн UTF-16 единиц на поле; проверка выполняется до транзакции, с сообщением об ошибке, без замены сохранённого черновика.

Медиа копируются через .part в отдельный diary_media, проверяются по заголовку и декодеру, получают SHA256/assetId. JPEG/PNG/WebP: до 20 МБ / 40 Мп. MP3/M4A/WAV: до 100 МБ. Для M4A принимается профиль ftyp M4A/M4B; универсальные видеоконтейнеры isom/mp4 отклоняются. Отмена/ошибка не меняет ссылку блока. Оригинальный файл пользователя не перемещается и не удаляется. При запуске собираются только неиспользуемые файлы дневника, с учётом ВСЕХ публичных и авторских ссылок, в том числе при выходе из аккаунта. Во время редактирования/Undo очистки нет. Если JSON повреждён, он сохраняется, остальные записи доступны, а очистка файлов пропускается.

Общий layoutDiary использует TextPainter, реальные стили, ширину, высоту и TextScaler. Текст режется по графемам без потери CRLF, пробелов и эмодзи; абзацы предпочтительны. Изображение и аудио атомарны, изображение contain + раскрытие. Медиа занимают одинаковый слот при доступном файле и ошибке. При большой доступности страница прокручивается; алгоритм всегда продвигается. Расчёт отдаёт управление каждые десять страниц; число страниц не сохраняется в БД. При репагинации используется blockId/textOffset и соседний сохранившийся блок. Предпросмотр и подсчёт страниц редактора используют тот же рендерер и геометрию читателя.

Аудио использует just_audio/audio_session. Одна активная дорожка, seek, продолжение сохранённой позиции блока, повтор после конца, известная/неизвестная длительность, загрузка/ошибка/повтор. Слайдер забирает горизонтальный жест, листание страницу не меняет. Пауза при переходе страницы, входе в другой экран, сворачивании, разрыве наушников и interruption; автоматическое продолжение отключено. Даже отложенная загрузка не запускает звук после ухода. При активной сессии дневник не запускает звук. При выходе освобождаются плеер и подписки.

Авторский журнал и читательский список используют один стиль, но разные действия. Поиск, тип и дата управляют представлением. Drag доступен только без фильтра/поиска, в режиме «Вручную». Порядок локальных черновиков сохраняется одной SQLite-транзакцией. Для опубликованных записей требуется серверное подтверждение: до него список не переставляется и публикация не удаляется. Удаление подтверждается с названием и отдельным предупреждением для публичной записи.

Главная показывает только короткое послание первой опубликованной записи в авторском порядке. Лаймовая вкладка на кромке открывает ту же запись или пустой журнал. Прежняя строка со стрелкой удалена. В локальных debug-сборках есть явная команда «Локальный автор · тестовый режим». Она разрешает работать на телефоне без ещё не настроенного OAuth, но блокирует облачные операции. В release этот путь не включается.

SQLite v4→v5 добавляет только diary_removed. Старые таблицы и payload не переписываются массово. Tombstones и сравнение версий защищают известную удалённую редакцию от повторного появления, более новая повторная публикация того же ID допустима. Разные ревизии страниц перечитываются один раз до обновления кэша; ошибки не меняют действующий каталог.
