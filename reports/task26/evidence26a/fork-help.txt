Manage disposable copies of a running Product

Usage: nrz fork [OPTIONS] --product-id <PRODUCT_ID> <COMMAND>

Commands:
  plan    Preview topology, data access, blockers and expected cost
  usage   Read measured costs for the copy and its resources
  policy  Manage the Git pull request policy for an exact Product Source
  create  Create a copy from an explicit running parent
  show    Show the copy, its source versions, resources and current cleanup receipts
  update  Update selected Services while keeping the copy's database and test data
  retain  Keep a copy available for QA until the specified instant
  delete  Request cleanup and return its current state
  help    Print this message or the help of the given subcommand(s)

Options:
      --product-id <PRODUCT_ID>  Product owning the copy
      --json                     Machine-readable JSON output [env: NRZ_JSON=]
      --human                    Force human-readable output; suppresses --json/NRZ_JSON and auto-JSON in non-TTY environments [env: NRZ_HUMAN=]
      --token <TOKEN>            API token for authentication [env: NRZ_TOKEN=]
      --workspace <WORKSPACE>    Workspace slug to use [env: NRZ_WORKSPACE=]
  -h, --help                     Print help
