# ДОПОЛНЕНИЕ №16-Б К ДЕЙСТВУЮЩЕМУ ЗАДАНИЮ №16
## Стабилизация Google-авторизации, загрузки контента и реального пути публикации
**Проект:** Алхимик / Сульфи. **Дата:** 12.11.2026. **Статус:** корректирующее ТЗ для Codex, продолжение №16/16-А, не №17.

## Изначальная задача
Из существующих, уже реализованных частей довести до работы на двух физических телефонах путь: MASTER Google → модуль «Индукция Элмана вариант 2» и три точных аудиозависимости → приватное физическое хранилище → каталог с подтверждённой публикацией → дневниковый анонс с exact ContentLink → CLIENT Google → установка/проверка SHA → офлайн-сессия со звуком. После этого можно приглашать закрытых тестировщиков и наполнять систему содержанием.

## Что произошло на настоящих устройствах, чего не показывают старые CI
- Вход через Google на двух устройствах первоначально сработал. Сервер вернул MASTER и разрешил контрольную master-публикацию; на CLIENT вернул CLIENT и подтвердил запрет публикации. Позднее при повторных запросах возникли `AUTHENTICATION_FAILED` и сообщения «Войдите через Google заново».
- В мастерской карточке при загрузке ~2.3–2.43MB получены `SocketException: Failed host lookup: script.google.com (errno=7)`, `HttpException: Software caused connection abort` и ошибки авторизации. Доходило до 100% отправленных байтов, но завершения/верификации на сервере не подтверждено. У дневниковой записи публикация висела слишком долго и не завершилась.
- «Облачный каталог», «Каталог публикаций» со статусами `draft`/`failed`, «Очередь синхронизации», локальный предпросмотр дневника **УЖЕ СУЩЕСТВУЮТ**. Не создавать заново. Ошибка с отсутствующим предпросмотром была снята: он открывается нажатием на запись.
- В меню модуля «Экспортировать модуль» — локальный ZIP на устройство, не серверный каталог; его сохранить. Требуются самостоятельные операции «Добавить в каталог» и «Подготовить к публикации».
- «Добавить обложку» на карточке есть, но миниатюра/сохранность выбранной обложки по скриншотам не подтверждены. Не объявлять отсутствие backend-функции без проверки кода.
