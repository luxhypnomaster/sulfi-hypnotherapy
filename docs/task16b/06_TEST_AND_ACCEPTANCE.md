# QA / acceptance-matrix
Всего **80 уникальных критериев** с ID `AUD/AUTH/TRF/CAT/MED/UX/REL` в `ACCEPTANCE_MATRIX.csv`. Реальный изначальный статус каждого — NOT_RUN. Codex обновляет по доказательствам, не ставит PASS за наличие кода без теста.

## Entry/Exit gates
- P0 AUTH и TRF нельзя принимать без подтверждения безопасной сессии и upload receipt; CAT нельзя принимать без реальной публикации Master и установки Client.
- Не нужен новый сервер. Test-only CI не даёт live PASS. Пропуск owner deployment approval оставляет live smoke BLOCKED, а не препятствует сдаче безопасных code-исправлений.
- Любой сбой может быть root cause DNS, radio, token, request handling, GAS quota, Drive latency; локализовать подтверждённым trace. Тайминг не подменять оценкой 51:42 прежнего CI.
- Обязательная таблица изменений к старой матрице 147 (она продолжается независимо) и хотя бы минимальный телефонный сценарий, описанный в `08_ANDROID_PHONE_QA.md`.

## Отчёт
`PASS` — точно воспроизводимый/проверенный критерий, источник указан; `PARTIAL` — часть с перечислением; `BLOCKED` — внешний непреодолённый блокер; `NOT_RUN` — не выполняли. Любые изменения статуса опирать на файлы, команду, CI run, screenshot proof и отсылку к записи владельца.
