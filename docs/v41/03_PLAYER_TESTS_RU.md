## Рекомендованные unit/widget/integration проверки

- Unit: расчёт общего времени, paused progress, freeWork extension, seek, skip, переход назад, unknown duration.
- Unit: построение сокращённого списка фаз и полного списка текущей фазы, 2× один moduleDefinition с разными instances, direct-track.
- Widget: layout compact device; 6 semantic buttons; один Pause и один Stop; scrolling на активный track; цвета и состояния.
- Integration: реальный audio_service/media engine, interruption, skip while paused, lock-screen background, resume with checkpoint.
- Manual device: Samsung/Android с потухшим экраном, Bluetooth disconnect, звонок, 5–15 минут FreeWork и длинная тишина — NOT TESTED без телефона.
