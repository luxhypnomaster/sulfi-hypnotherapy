# ВЫБОР ЭКСПОРТА / ИМПОРТА / ИМЕНИ ФАЙЛА — ТОЧНЫЙ UX

## Что увидел владелец
Выборочный ZIP экспортировался, на телефоне Android архив распаковывается как `manifest.json` (4.11 КБ в одном тесте) и каталог `blobs/` (3 элемента). Файлы могут быть тремя аудиоблобами, но **только inspect manifest может подтвердить** тип/хеш/состав. Паузы хранятся в графе шагов, а не как самостоятельные MP3. Это подтверждённый формат CAPSULE, не работоспособность отдельной установки.

## Имя ZIP
1. `Sulfi_exp_<transliterated_original_title>_DD.MM.YY.zip` (русские буквы в латиницу, никакого семантического перевода; `Ё`→`Yo`, `Й`→`Y`, `Ы`→`Y` и т.д., последовательная детерминированная таблица). Например `Sulfi_exp_Induktsiya_Elman_09.11.26.zip`.
2. Дата — локальные часы при экспорте; `.zip` всегда один раз. Unicode title внутри manifest оригинальный без потерь, filename не служит уникальным ID контента. Идентичность — manifest type/logicalId/revision/digest. Для совпадающих имён на телефоне предупреждать или суффикс `-2`/дата+время по сохранению безопасным способом, не делать silent overwrite.
3. Санитизация: slash/backslash/colon/Windows reserved, `..`, NUL/control/emoji/невозможные char заменить на `_` или исключить; многократные `_` схлопнуть; длина basename ограничена без ломания Unicode при промежуточном преобразовании. Пустое имя→`Untitled`. При переводе fileName избирается safe ASCII, но описание в UI/manifest сохраняет оригинал.
4. Full data backup file `Sulfi_backup_DD.MM.YY.zip` и отдельное название UI «Резервная копия». Его структура по прежнему `scope: full`, не путать с одним модулем. При restore подтверждать возможные последствия и показывать conflicts before commit.

## Кнопка импорта
Сейчас settings библиотеки показывает «Локальный каталог материалов» и «Резервная копия и обновления». Системное приложение Android показывает «Извлечь», но это не команда Сульфи. Добавить доступное явное действие «Импортировать ZIP» в понятном месте (каталог или рядом с управлением хранилищем). Это должен быть путь к существующему LocalCatalogSource, не другой importer. Отображать type/title/version/origin/size/closure/missing files; preview, cancel, install; уже установленное → «Установлено», без перезаписи.
