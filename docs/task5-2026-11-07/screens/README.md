# Настоящие Flutter-рендеры задания 5

Из `test/task5_ui_test.dart`, рендер 412×915 logical px, Roboto и Material Icons, реальные экраны и локальная SQLite. Изображения не являются скриншотами установленного Android: эмулятора/телефона в окружении нет. Вложенное аудио — 12 секунд синтетической тишины, не пользовательская запись.

- `diary-recorder-finished.png`: запись для дневника, необязательное имя, без тегов/категорий/модуля, тот же движок.
- `diary-after-save.png` / `diary-attached.png`: возвращение в сохранённый черновик с текстом и отдельным аудиоблоком.
- `history-detail-top.png`: сведения, заметка, начало полностью раскрытой структуры.
- `history-detail-bottom.png`: сохранённые границы фаз/модуля, прямые паузы и две нижние кнопки в общем потоке прокрутки.
- `history-editor.png`: временный архивный план в существующем редакторе, без создания постоянных модулей.

Воспроизведение: `flutter test test/task5_ui_test.dart --dart-define=SULFI_TASK5_SCREENSHOTS=/absolute/output/path`.
