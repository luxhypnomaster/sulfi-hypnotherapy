# Ручная проверка на Android — первый этап

Статус: **не выполнена на физическом телефоне**. Цель — проверить нативный picker, декодер и звук, которые не заменяются unit/widget-тестами. Используйте только собственные несекретные тестовые аудио; не добавляйте их в GitHub.

1. Собрать `flutter build apk --debug`, установить `adb install -r build/app/outputs/flutter-apk/app-debug.apk`. Записать модель телефона, Android, SHA сборки и результат каждого пункта. Желательно проверить API 24 и современный API 36.
2. Включить авиарежим. Открыть приложение: русский интерфейс, пустая библиотека, три вкладки, сведения о локальных данных. Убедиться, что нет запроса микрофона, аккаунта или широкого доступа к файлам.
3. «Добавить аудио» → отменить системный выбор. Ничего не добавляется, ошибки нет. Повторить выбор, затем отменить редактор названия: запись не появляется.
4. Импортировать по одному настоящему MP3, M4A (AAC) и WAV (PCM). Сравнить длительности с внешним плеером (разница округления до секунды допустима), изменить названия и категории. Проверить размер и формат.
5. Импортировать второй файл с тем же исходным названием. Записи должны быть независимыми. Переименовать одну, поменять категорию, найти по части названия и категории.
6. Прослушать каждый формат: старт, пауза, продолжение, остановка, воспроизведение другого файла и повтор после окончания. Одновременно должен звучать только один трек. Воспроизведение и фактическая длительность проверяются на слух/таймером.
7. Выйти на домашний экран и заблокировать телефон во время предпрослушивания: **текущий этап должен остановить звук**, не продолжать автоматически после возврата. Проверить входящий звонок/аудиофокус, извлечение проводных наушников, отключение Bluetooth. Автоматического продолжения после прерывания не должно быть.
8. Перезапустить приложение, затем удалить внешний оригинал одного импортированного файла и снова перезапустить: название, категория, длительность и прослушивание внутренней копии должны сохраниться.
9. Попробовать пустой WAV и повреждённый файл с расширением MP3/M4A/WAV: понятная ошибка, нет новой записи/вечной загрузки. Неподдерживаемые расширения обычно отсекает picker; проверьте переименованный неаудиофайл.
10. Удалить аудио: отмена подтверждения сохраняет запись, согласие убирает её и останавливает её предпрослушивание; внешний оригинал остаётся. Для debug-проверки недостающего файла можно удалить одну внутреннюю копию через Android Studio Device Explorer: прослушивание должно показать ошибку, запись должна оставаться доступной для удаления.
11. Проверить поворот, экран шириной 320 dp, крупный системный шрифт и экранную клавиатуру в редакторе. Нужны читаемые подписи и доступные кнопки без переполнения.
12. «О приложении и данных» → удалить всё: до подтверждения ничего не меняется; после — пустая библиотека, нет звука, внешние файлы на месте; перезапуск не восстанавливает удалённые записи.
13. Проверка обновления: с непустой библиотекой установить поверх APK с тем же applicationId/подписью и большим versionCode; библиотека и звук сохраняются. **Не удалять приложение ради смены подписи** — это удаляет данные. Старый APK поверх нового не считается проверенным способом отката.

Не заявлять проверенными здесь фоновые сессии, микрофон, запись темы, Bluetooth-маршрутизацию во время записи или безопасный выход из сессии: этих функций пока нет.
