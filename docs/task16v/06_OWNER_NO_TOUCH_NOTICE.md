# Важная записка владельцу, пока проверяется инцидент

**Подтверждено:** пользователь провёл обычное Android-обновление MASTER24→MASTER25. После него созданные ранее локальные треки, модули, черновики дневника перестали отображаться. **Не подтверждено:** физическое удаление SQLite/media.

**Пожалуйста, не делайте пока**: uninstall/reinstall; clear storage/cache; downgrade APK24; новый импорт капсулы; создание одноимённых объектов; удаление failed drafts/очереди; logout/account switch по просьбе бота без безопасного плана; запуск новых сборок. Сохраните имеющиеся ZIP-экспорты, если существуют.

Вся информация о личных аудио и дневниках чувствительна. Не присылайте разработчику архивы личных материалов, Google token, пароль или полную SQLite базу без отдельного осознанного выбора и безопасного канала. Фотография экрана пустой библиотеки и системной версии Android может помочь; без необходимости не запрашивать.

Нельзя обещать: «капсула автоматически восстановится». Автозагрузка личных черновиков из Google не была доказана.

Установку будущей APK26 и любые действия по восстановлению обсуждать **после** документированного read-only расследования, подтверждённой сохранности и инструкции, одобренной владельцем.
