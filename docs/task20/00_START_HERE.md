## Зачем этот пакет

Владелец временно сокращает ранее планировавшееся комплексное №20, чтобы использовать оставшийся недельный лимит Codex. Ближайший законченный контур: публикация согласованной редакции каталога → быстрая проверка изменений CLIENT/MASTER → атомарное локальное применение → локальная дневниковая витрина и конфигурация MASTER.

ВАЖНО: Новый сервер, Supabase/TatNet, production миграции, новые user accounts и обширный CLIENT Rubedo-redesign в это №20 НЕ входят. Работы №19 G2–G7 и будущий комплексный объём сохраняются в backlog; номер №19 остаётся PARTIAL, не объявлять закрытым. Мониторинг квот и server-to-Google-Drive backup утверждены владельцем как будущие функции MASTER/Управление и внесены в S-D-ADM-001 REQ-ADM-022…027; в №20 делать только независимый безопасный задел, никакого выдуманного провайдерского quota API или псевдобэкапов.

## Лимиты и смысл слова «готово»

Владелец ожидает интенсивной непрерывной работы Codex на этот пакет, максимально используя оставшийся недельный бюджет, но лимит не является основанием бесконтрольно менять систему, бесконечно гонять повторяющиеся неуспешные сборки или расходовать платные услуги.
