# Выход и приёмка
RESULT.md — итоговый статус, endpoint, версии, что реально доказано, границы следующего этапа.
CHANGES.md — ветка, base SHA, commit, diff, draft PR при наличии, без merge.
TESTS.md — T26-01…18, ожидаемое/фактическое, timestamps, доказательства, повторные попытки, разделение local/live/owner.
ISSUES.md — блокеры, риски, варианты и точные шаги владельца.
DEPLOYMENT_RUNBOOK.md — воспроизводимые deploy/update/rollback, восстановление из прерванной стадии, no duplicates.
PROVIDER_STATE.md — закрытый паспорт project/service/SQL/function/KV IDs, URL, регион, версии, ставки, Usage до/после, режим сна/остановки, следующий расход; не размещать в публичном Git.
NEXT_STAGE.md — подключение существующего IAM/P22, дальнейшие Postgres migrations, Drive gateway, snapshots, durable ops, телеметрия без пересоздания.
Отчёты сохранить в For_Codex/Сервер — Задание 26/Отчёты — Задание 26 при наличии разрешённого доступа; иначе вернуть через штатный механизм Codex и сообщить блокер. Никаких значений токенов, паролей, signing secrets. Не менять отчёты №25. Не выдавать отсутствие live теста за PASS. Владелец фиксирует лимиты Codex 5ч и недели до/после; Codex сообщает число повторов, причины и фактические тесты, не выдумывает расход лимитов.
