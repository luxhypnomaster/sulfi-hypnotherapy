# Доступ и остановка
NRZ_TOKEN — имя защищённого секрета авторизации ONREZA CLI/API; значение намеренно отсутствует. Владелец ранее создал временный широкий токен; он был раскрыт в чате, рекомендована ротация до использования. SEC-005 фиксирует ротацию. Нужна проверка поддержки защищённого runtime secret/разрешённого механизма авторизации именно в используемом Codex окружении. Не считать резервную копию на Google Drive автоматическим доступом; не извлекать секрет из Drive/чата, не печатать env, не передавать в URL, не писать в файлы/Git/отчёты. Не обходить network/secret policy. Проверка присутствия без значения, затем официальная read-only проверка identity/workspace. При setup-only секрете — не копировать в незашифрованный файл и не обходить ограничение. Если нет безопасного runtime доступа, продолжить локальную часть, вернуть BLOCKED_OWNER/BLOCKED_ENV и конкретный шаг настройки. Ограничить онлайн-операции тестовым workspace; запрет на изменение подписки, участников, прав, чужих ресурсов, production и внешних аккаунтов. Платные обязательства 0, добавочный расчётный предел 10 ₽ из включённого кредита — при подтверждении владельца; если не подтверждён, запросить его до создания. Не обещать доступ к API, кредиту или live deploy без фактической проверки.
