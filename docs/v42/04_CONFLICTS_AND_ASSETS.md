# СУЛЬФИ v4.2 — замены устаревших требований, файлы, границы

## Явные исправления устаревших инструкций

| Было в v4.0/v4.1 | Сейчас обязательно |
|---|---|
| `Дневник не реализовывать` | **ОТМЕНИТЬ:** Дневник включён в обычный MVP, реализовать функциональную часть и безопасный API-контракт. |
| `Никакого облака` в v4.0 | Исключение **только для авторского дневника**: безопасная синхронизация публикаций, без секретов в клиенте. Остальные личные аудио остаются локальными. |
| `Шесть нижних действий` в редакторе сессии | **Ровно три в один ряд:** Выбрать / Сохранить / Применить. |
| `Большие видимые кнопки добавления` внутри фазы | **Одна компактная** кнопка `+ Добавить`, полноценное контекстное меню. |
| `Silence / FreeWork` как две пользовательские опции | **Одна «Пауза»** при добавлении; старые данные сохранять через совместимый слой. |
| `Описание` и поле секунд для нового интервала | **Золотые часы** с минутами/секундами, без описания. |
| `Завершить сессию` в плеере | **`Закончить сеанс`**, затем история после реального завершения/прерывания. |
| Зеленовато-жёлтая интерпретация кнопки с PNG | **Ярко-зелёный, НЕ жёлтый**. Текст v4.2 выше неидеальной колористики картинки. |
| Огромные карточки шаблонов/аудио | Компактные строки, тап по строке выбирает/добавляет. |
| `⋮` может занять место кнопки раскрытия | `+ / −` в неизменной точке, `⋮` отдельно внутри раскрытого блока. |
| Запись в фазе требует привязки к конкретной фазе | Категория — только метаданные; экземпляр выбирает фазу при включении в план. |

## Важные границы реализации

- Не создавать новый референс колбы: экран уже утверждён.
- Не использовать посторонние коллажи дневника, вариации колбы, макеты «личного дневника пользователя».
- Дневник — авторское содержание Сульфи, а не клиентские сведения. Продакшн публикацию не заявлять без настоящей защищённой инфраструктуры.
- Для сравнений скриншотов использовать **реальные снимки запущенного Flutter-приложения**, а не обработку референса.
- Откат/сборка, отдельная ветка/PR, отсутствие удаления личного контента и фиктивных PASS — обязательны.
