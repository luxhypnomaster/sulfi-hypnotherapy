## Обязательное уточнение: каталог публикаций и дерево хранения

ПЕРЕД любым server/code/deploy прочитать **CONTENT_CATALOG_AND_STORAGE.md**. Требование владельца не равно «положить ZIP на Google Drive»: реализовать редактируемые **аннотации** у треков/модулей, типизированный online каталог для клиента, инсталляцию с exact version dependencies, отдельную авторскую форму подготовки и публикации, и автоматический idempotent bootstrap закрытой папки **«Хранилище Сервера Проекта Алхимик»** внутри существующей папки **«Проект Алхимик»**. Файлы по физическим папкам не заменяют каталог; публикация не должна автоматически открывать приватные данные. Проверить ACL существующей родительской папки до сохранения личных дневников; при небезопасной наследуемой видимости не загружать данные, выбрать защищённый owner-only root с указанным обоснованием.
