# Реальные Flutter-рендеры задания 6

Тест `test/task5_ui_test.dart`, настоящие виджеты приложения и SQLite, 412×915 logical px (PNG с масштабом 2). Это не скриншоты установленного Android. Данные искусственные: изображение-заглушка и 12 секунд тишины вместо личной записи.

- [История с вложением](history-attachments.png): новый раздел между заметкой и раскрытым ходом сессии; голос, камера, изображение и миниатюра.
- [Сквозной мини-плеер](global-preview.png): общая панель после перехода на другой экран, реальная навигация и общий сервис.
- [Верх истории](history-detail-top.png) / [низ истории](history-detail-bottom.png): прежняя раскрытая структура и два действия сохранены.
- [Архивный редактор](history-editor.png): прежний путь «В редактор».
- [Компактный диктофон](diary-recorder-finished.png), [после сохранения](diary-after-save.png), [вложение дневника](diary-attached.png): регрессия существующего мультимедийного дневника; для истории используется тот же диктофон.

Воспроизведение: `flutter test test/task5_ui_test.dart --dart-define=SULFI_TASK5_SCREENSHOTS=/absolute/output/path`. Флаг сохраняет прежнее имя для совместимости тестового набора. Тесты проверяют просмотр миниатюры, подтверждение удаления и неизменность снимка сессии, а также навигацию и информационное окно общей панели.
