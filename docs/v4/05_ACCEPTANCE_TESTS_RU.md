# Сульфи v4.0 — МАТРИЦА ПРИЁМКИ И РЕГРЕССИИ

**Цель:** дать Codex проверяемые критерии вместо субъективного «похоже на макет». Для каждого пункта в отчёте указать `PASS / FAIL / NOT TESTED`, метод, среду и известное ограничение. Если физический Android отсутствует, честно ставить `NOT TESTED` для устройства. В первую очередь не потерять сохранённые записи и обеспечить реальное исполнение времени.

## A. Архитектура и терминология (A01–A12)

- [ ] **A01.** Главные слова в UI: `Фаза`, `Модуль`, `Трек`; нет одиночных «блоков» в счётчиках.
- [ ] **A02.** При 2 аудио и 2 интервалах UI считает `2 трека · 2 интервала`, total правильный.
- [ ] **A03.** В библиотеке `Теги`, не «Метки через запятую»; теги участвуют в поиске.
- [ ] **A04.** Каталог фаз содержит все десять утверждённых названий и порядок рекомендаций.
- [ ] **A05.** Пустая новая конфигурация показывает типовые фазы, но НЕ содержит фиктивных mp3/«Разведку» и НЕ запускает фальшивый сеанс.
- [ ] **A06.** Пустые/выключенные фазы видны компактно в полноэкранном редакторе и скрыты на главной; disabled не расходуют время.
- [ ] **A07.** В одной сессии две независимые фазы `Проработка` с разным содержимым и паузами.
- [ ] **A08.** Один `ModuleDefinition` добавлен дважды **внутри одной `PhaseInstance`** через `Добавить модуль`; оба экземпляра сохраняются после перезапуска и отличаются по настройкам.
- [ ] **A09.** `Добавить модуль` допускает модуль, не рекомендованный для этой фазы, через `Все модули`.
- [ ] **A10.** Выбор модуля из трёх треков вставляет все три по авторскому порядку; ручное выключение/перестановка/повтор каждого сохраняется.
- [ ] **A11.** Повторное открытие фазы НЕ добавляет вторые копии модуля, пока пользователь явно не нажал добавить.
- [ ] **A12.** Отдельный свободный трек/интервал может стоять между двумя модулями; плейлист реально исполняется в таком порядке.

## B. Импорт, каталоги, модульные связи (B01–B10)

- [ ] **B01.** Импорт MP3 из picker создаёт читаемый локальный управляемый аудиофайл, после перезапуска доступен.
- [ ] **B02.** Импорт M4A/WAV — воспроизводится либо честно выдаёт неподдерживаемый формат (без фиктивного импорта).
- [ ] **B03.** При импорте доступны варианты `Новый модуль` / `Существующий модуль` / `Без привязки`.
- [ ] **B04.** Новый модуль можно создать с одним треком и затем добавить второй отдельным импортом; название и порядок сохраняются.
- [ ] **B05.** Существующий модуль принимает новый трек; уже сохранённые экземпляры этого модуля в шаблонах НЕ меняются самопроизвольно.
- [ ] **B06.** Отдельный импорт без модуля сохраняет трек в библиотеке; позже его можно добавить в любой модуль.
- [ ] **B07.** Один и тот же трек из библиотеки применяется дважды с независимыми задержками.
- [ ] **B08.** Категория `Установки` не запрещает использовать трек в фазе `Индукция` по осознанному выбору автора.
- [ ] **B09.** Удаление зависимого аудио/модуля предупреждает и не уничтожает историю/другие несвязанные файлы.
- [ ] **B10.** Редактирование `ModuleDefinition` не мутирует `ModuleInstance`, `SessionTemplate`, замороженный `SessionRun` без явного действия пользователя.

## C. Главная, структура, навигация, графика (C01–C12)

- [ ] **C01.** Старой компоновки из двух узких колонок нет; структура на всю ширину, длинные названия читаемы.
- [ ] **C02.** Список из 30 треков прокручивается внутри области до активного шаблона, нижняя CTA/меню остаются доступными.
- [ ] **C03.** Сводка содержит предварительный №, **день недели, дату, живое время**, тему и плановую длительность без потерянной даты.
- [ ] **C04.** Тема и заметка реально редактируются; карточка активного шаблона не исчезла ради художественного референса.
- [ ] **C05.** Большая CTA показывает **«НАЧАТЬ ТРАНСФОРМАЦИЮ»**, не старый текст.
- [ ] **C06.** Нижние кнопки **ровно 4**: `Записаться к мастеру` · `Библиотека` · `Шаблоны` · `История`.
- [ ] **C07.** На нижней панели **НЕТ микрофона/«Записать»**; запись доступна из библиотеки и редактора фаз.
- [ ] **C08.** Первой кнопке назначена розовая спираль, в том же дерзком стиле, без перекрытия лица Сульфи.
- [ ] **C09.** В редакторе явно видны действия создания фазы и модуля; «Выбрать аудиовыход» удалено как ложная функция.
- [ ] **C10.** UI не является целой иллюстрацией с неробочими нарисованными кнопками; все действия Flutter доступны касанию, клавиатуре и screen-reader.
- [ ] **C11.** Название Android на launcher `Сульфи`, в самой иконке только розовая спираль, adaptive shapes не обрезают знак.
- [ ] **C12.** Проверить реальные размеры Android 360dp/412dp, системные панели и масштаб шрифта 1.3–1.5: текст не катастрофически обрезан, кнопки не перекрыты.

## D. Паузы, редактор времени и расчёты (D01–D08)

- [ ] **D01.** Пауза перед **первым** аудиотреком 01:30 воспроизводится до него, а не после.
- [ ] **D02.** Перенос второго трека переносит и его `delayBefore`, чужие паузы не мигрируют.
- [ ] **D03.** Выключенный трек исключает и его паузу из итоговой длительности.
- [ ] **D04.** Общий расчёт: 1:54 + 2:33 аудио + 5:00 работа + 0:30 пауза = **9:57**; никаких двойных сумм.
- [ ] **D05.** Золотые часы: минутный и секундный диски **независимы**, секундный шаг 5с, минутный 1м; ввод вручную работает.
- [ ] **D06.** `Обнулить` не обнуляет все паузы шаблона; `Применить` изменяет лишь выбранную, Cancel не меняет черновик.
- [ ] **D07.** Кнопки предпрослушивания соседних треков выбирают именно ближайшие аудиофайлы из flattened-плана, игнорируя интервалы, без создания `SessionRun`.
- [ ] **D08.** У свободной работы длительность регулируется; открытое время помечено как оценочное.

## E. Диктофон (E01–E14)

- [ ] **E01.** Реальный экран соответствует `02_RECORDER_APPROVED.png`: **параметры сверху, запись ниже, отмена слева, сохранение справа**.
- [ ] **E02.** Вместо микрофона в верхней зоне розовая спираль; рядом аккуратная перьевая ручка, не карандаш.
- [ ] **E03.** Центральная спираль реально запускает запись и продолжает при паузе; не только декоративная анимация.
- [ ] **E04.** В исходном состоянии нет возможности нажать `Воспроизвести` пустой файл или `Сохранить трек` без записи.
- [ ] **E05.** Разрешение на микрофон запросится; отказ показан явно, нет подставной «идёт запись».
- [ ] **E06.** 10с записи + 10с паузы + 10с записи = около 20с звука, таймер не растёт в паузе.
- [ ] **E07.** `Завершить` закрывает запись, но НЕ сохраняет автоматически библиотечный трек.
- [ ] **E08.** `Воспроизвести` после завершения даёт слышимый preview; в это время микрофон не работает.
- [ ] **E09.** `Удалить` удаляет несохранённый дубль с подтверждением, а не сохранённый MP3.
- [ ] **E10.** `Отмена` при несохранённом файле подтверждается; без записи Back сразу выходит.
- [ ] **E11.** `Сохранить трек` создаёт один реальный `AudioAsset`, даже при двойном тапе.
- [ ] **E12.** Сохранённый трек попадает в `Мои аудиозаписи`; привязка к существующему или новому каталожному модулю по выбору корректна.
- [ ] **E13.** Нет принудительной привязки к модулю и нет незаметной подмены уже сохранённого шаблона.
- [ ] **E14.** Отсутствие памяти, ошибочный codec, занятый микрофон, уход приложения в фон корректно отрабатываются без объявления успеха.

## F. Сеанс и фоновый режим (F01–F15)

- [ ] **F01.** Нажатие CTA создаёт ровно один `SessionRun`; до этого открытие/редактирование истории не создают.
- [ ] **F02.** Исполнение следует **точному порядку** видимых элементов (фазы → модули → треки/интервалы), с паузами перед ними.
- [ ] **F03.** `Пауза` и `Продолжить` — одно взаимоисключающее основное действие, действует и на тишину/FreeWork.
- [ ] **F04.** `Завершить работу` видно только в FreeWork, переходит к следующему реальному элементу.
- [ ] **F05.** `Продлить работу` (+5 минут) меняет только это исполнение, не исходный шаблон.
- [ ] **F06.** `Перейти к выходу` из середины сессии запускает только доступный выходной контент, минуя план; история отмечает досрочность.
- [ ] **F07.** Если выходного трека нет, показывать реальную возможность прерывания/ориентации, не изобретать текстовую MP3.
- [ ] **F08.** `Прервать сессию` запрашивает подтверждение и даёт статус `Прервана`; это не `Завершена`.
- [ ] **F09.** Нормальное завершение всех элементов даёт `Завершена`; completion через Exit даёт отдельный status и список пропусков.
- [ ] **F10.** Locked screen: MP3 продолжает играть, screen off допустим, системная пауза реально управляет сеансом.
- [ ] **F11.** Locked screen: тишина 2 минуты исполняется до следующего MP3 даже с выключенным экраном.
- [ ] **F12.** Сворачивание приложения в другую программу НЕ сбрасывает UI-таймеры/паузы и не создаёт второй сеанс.
- [ ] **F13.** При отключении наушников аудио не начинает неожиданно звучать через динамик; обработка звонков/аудиофокуса проверена.
- [ ] **F14.** При принудительном закрытии процесса ОС нет ложного `Завершена`; checkpoint позволяет предложить восстановление/прерывание.
- [ ] **F15.** Все фоновые сценарии **на физическом Android**, включая длительную тишину, проверены либо честно помечены NOT TESTED.

## G. Черновик, шаблоны, история, контакты (G01–G13)

- [ ] **G01.** Черновик автосохраняется, перезапуск открывает его, не сбрасывает из шаблона.
- [ ] **G02.** Смена шаблона при изменённом черновике предупреждает, исходный шаблон не переписывается.
- [ ] **G03.** `Применить и вернуться` не запускает сеанс.
- [ ] **G04.** История содержит день недели, полную дату/время, статус, фактическое время и тему в компактной карточке, без гигантских заметок.
- [ ] **G05.** `Повторить сессию` по прерванному запуску переносит **полный план старта** в новый черновик и НЕ запускает его.
- [ ] **G06.** `Создать шаблон из сессии` не меняет текущий черновик и старый `SessionRun`, включая плановые пропущенные элементы.
- [ ] **G07.** Старые исторические дни недели не меняются после смены timezone устройства.
- [ ] **G08.** Telegram из контактов открывается внешним способом; ссылка конфигурируема, не выдумана.
- [ ] **G09.** Email открывает mailto; если приложение не установлено, адрес можно скопировать.
- [ ] **G10.** Внешний контакт не отправляет заметки/аудио/темы автоматически.
- [ ] **G11.** Условия отсутствующих Telegram/email обрабатываются без сломанных кнопок.
- [ ] **G12.** Миграция старого `2 MP3 + 2 интервала` проходит с сохранением последовательности, аудио, пауз и авторских имен.
- [ ] **G13.** Миграция идемпотентна; отсутствие MP3 отображено честно без подмены.

## H. Итоговый quality gate

- `flutter analyze`: PASS/FAIL, версия SDK;
- `flutter test`: PASS/FAIL, число/наименования тестов;
- `flutter build apk`: PASS/FAIL/не было Android SDK;
- проверка на реальном Android: PASS/FAIL/NOT TESTED для фонового воспроизведения и звукозаписи;
- скриншоты главной, раскрытого редактора, диктофона и истории после реальных изменений;
- список изменённых файлов, миграций, известных ограничений, ручных проверок;
- feature branch от `develop`, PR на `develop`, `main` не менять без прямой команды.

**Статус `PASS` не ставить, если это только нарисовано или лежит в заглушке.**
