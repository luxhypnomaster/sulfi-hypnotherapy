# Тестовые данные

`catalog.observed-empty.json` — исходные 79 байт проверенного каталога. `entry.example.json` — демонстрационная запись для тестового адаптера, иллюстрирует предлагаемый клиентский формат. Для локального теста сопоставить `demo-portrait-image` с `../references/01_reader_first_page.png`. Аудио ID требуют локальных тестовых файлов с правами на использование или синтетического источника тестового проигрывателя. Длительности в JSON служат данными примера. Разрывы страниц всегда вычисляются, поэтому fixture не фиксирует число страниц. Эти данные не загружаются в рабочий каталог и не входят в публичный релиз.
