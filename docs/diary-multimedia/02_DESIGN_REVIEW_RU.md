## Уточнения к макетам после просмотра

- Для кнопок листания использовать мягкий зеленоватый активный стиль и серый отключённый. На листе 2 из 3 обе активны. Фуксия на макетах кнопок — прежний вариант.
- Однострочное поле «Короткое послание» на макете демонстрирует короткий пример. В редакторе поле многострочное и растёт по мере ввода. Около четырёх видимых строк — ориентир для первой сборки. Предел высоты уточняется по примерке на телефоне.

## Журнал записей

| Узел | Что показывает референс | Что сделать в приложении |
| --- | --- | --- |
| Строка записи | Номер, название, дата, время и тип | Сохранить иерархию. Дать названию основной вес и место. Иконки типа сопровождать доступными названиями. Состояние черновика видит только автор |
| Действия | «Новая запись», карандаш, корзина, рукоятка | Только автору. Редактирование и удаление имеют отдельные зоны касания. Подтверждение показывает название записи. Drag не меняет номер |
| Сортировка | Референс показывает «По дате» рядом с drag | Для авторского порядка нужен отдельный режим «Вручную». Drag доступен только в полном ручном списке. Поиск/фильтр/дата не меняют фактический порядок |
| Плотность | Десять строк и крупный нижний декор | Список скроллируется. На 360 dp строки и иконки должны оставаться читаемыми и доступными. Крупный знак под списком допустим в пустой области, если это не уменьшает рабочую высоту |
| Цвет | Фуксия для контура, лайм для заметных акцентов | Оставить фирменную палитру. Карандаш и корзина различаются формой, удаление не зависит от цвета |

Первое открытие читательского журнала сохраняет авторский порядок. Набор и оформление расширенных фильтров по типам и дате сверить с репозиторием. Это управление представлением списка.

## Стикер на главной

| Область | Решение |
| --- | --- |
| Внешний вид | Кислотно-зелёная вкладка «Дневник» слегка выглядывает из-под верхней кромки планшета. Переиспользовать рамку и фирменные материалы приложения |
| Место | Вкладка прикреплена к кромке, визуально не образует новой строки. Удалить прежнюю строку и дублирующую стрелку из дневниковой точки входа |
| Содержание | Короткое послание первой опубликованной записи в ручном порядке. Название, длинный текст и встроенное листание на главной не выводить |
| Действие | Открывает первую страницу той же записи. При достоверно пустом каталоге ведёт к читательскому журналу |
| Доступность | Смысловая подпись «Дневник». Расширенная цель касания вокруг визуально маленького стикера. Не перекрывать существующие действия, safe area, основную кнопку и поля сессии |

Референс стикера показывает больше дневникового текста и навигацию внутри планшета. Это расхождение с согласованным поведением главной. Переносить из него форму, цвет и место крепления стикера.

## На художественное согласование

1. **Редактор.** Фуксиевые контуры блоков и лаймовая публикация продолжают стиль референсов. В макете у трёх типов блоков похожая система иконок. Окончательную плотность рамок, свечение и частоту спиральных разделителей сверить с автором.
2. **Продолжение.** На странице 2 отдельная вертикальная иллюстрация показывает, как встроится медиа. Для последней страницы предлагается оставить свободное место без крупного знака под текстом. Малый разделитель из визуального канона допустим, если не съедает площадь чтения.
3. **Журнал.** Предложение «Вручную» уточняет состояние сортировки. Внешний вид переключателя и место индикатора «есть черновик» проверить при сборке. Не добавлять новые декоративные элементы без согласования.
4. **Тестовый контент.** Заголовок опирается на найденный референс. Тексты продолжения и названия треков демонстрируют вёрстку. Они не являются готовой публикацией. Вложенная графика макета не заменяет оригинальные сигилы и другие бренд-ресурсы репозитория.

В споре между надписью на PNG и функциональным ТЗ приоритет у согласованных правил. Не запекать декоративный макет под интерфейс, не использовать фиктивные системные часы и не переносить лишние обводки, если мешают чтению.
