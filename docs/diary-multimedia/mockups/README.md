# Чистовые макеты для проверки

Все три экрана имеют размер 1080×1920. Визуальные предложения перечислены в `../02_DESIGN_REVIEW_RU.md`. Картинки предназначены для сверки Flutter-интерфейса. Иллюстрация внутри страницы 2 и миниатюра в редакторе имитируют пользовательский контент. Использовать оригинальные ресурсы приложения для фирменных элементов.

| Макет | Задание на создание |
| --- | --- |
| `01_author_editor.png` | Продолжить рамку первой страницы и язык управления журнала. Один вертикальный редактор, три типа блоков, видимые действия и счётчик страниц |
| `02_reader_page_02.png` | Сохранить рамку страницы 1. Начать сразу с текста, затем изображение и компактный аудиоблок. Две активные кнопки. В приложении обе мягко-зелёные, фуксия на PNG — прежний вариант |
| `03_reader_page_03.png` | Продолжение текста, плеер в состоянии воспроизведения, следующий абзац и финальная навигация. «Следующая» серая и отключена. «Предыдущая» активна, в приложении мягко-зелёная. Нижнее поле свободно от крупного знака |

Высоту поля «Короткое послание» реализовать по ТЗ. Оно растёт по мере ввода, начальный ориентир — около четырёх видимых строк.

Проверены читаемость подписей, состояния навигации, единый визуальный язык и отсутствие повторной шапки записи на продолжениях. Яркость разделителей, плотность рамок редактора и свободное поле финальной страницы оставлены на художественное согласование.
