# Сульфи · мультимедийный дневник

Пакет для Codex, редакция 1.1. Уточнены цвета навигации читателя и поведение поля короткого послания. Целевая база — существующее Flutter-приложение «Сульфи — Самогипноз», Android в приоритете. Исторически проект фигурировал как `sulfi-hypnotherapy`. URL, ветку и HEAD сверить в рабочем checkout.

| Файл или папка | Содержимое |
| --- | --- |
| [01_FUNCTIONAL_SPEC_RU.md](01_FUNCTIONAL_SPEC_RU.md) | Единое функциональное ТЗ |
| [02_DESIGN_REVIEW_RU.md](02_DESIGN_REVIEW_RU.md) | Журнал, стикер, привязка к референсам и решения на согласование |
| [03_DRIVE_APPS_SCRIPT_AUDIT_RU.md](03_DRIVE_APPS_SCRIPT_AUDIT_RU.md) | Фактический аудит Drive и маршрут проверки Apps Script |
| [04_ACCEPTANCE_TESTS_RU.md](04_ACCEPTANCE_TESTS_RU.md) | Приёмочные проверки, включая сбои и офлайн |
| [05_CODEX_TASK_RU.md](05_CODEX_TASK_RU.md) | Команда на запуск реализации |
| [mockups/](mockups/) | Редактор, страницы 2 и 3, по 1080×1920 |
| [references/](references/) | Визуальные источники, копии в формате 9:16 |
| [fixtures/](fixtures/) | Подтверждённая форма пустого каталога и пример записи для локальных тестов |

Начать с `05_CODEX_TASK_RU.md` и прочитать остальные документы до правок. В `02_DESIGN_REVIEW_RU.md` помечено, где референс задаёт канон и где чистовой макет предлагает компоновку для проверки автором. Реализовать интерфейс Flutter-виджетами. PNG служат ориентиром для сравнения. Цвета кнопок листания и высоту поля короткого послания брать из ТЗ. Эти детали на PNG отражают более ранний вариант.

Пакет охватывает дневник и его точку входа на главной. Прежнее ТЗ «только настройка паузы» относится к отдельной итерации. Если она открыта, вести дневник отдельной веткой или отдельным checkout от актуальной согласованной базы.
