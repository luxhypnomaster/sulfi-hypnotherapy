# Приёмочные тесты

Тестовые записи создавать в локальной базе или изолированном тестовом контуре. Рабочий каталог Drive используется только для проверенного чтения.

| ID | Проверка | Ожидаемый результат |
| --- | --- | --- |
| UI-01 | Скриншоты редактора, страницы 1, страниц 2 и 3, журнала, главной | 9:16 для визуальной сверки. Видны живые надписи, формы, состояния. Страницы 2+ без повторной шапки записи. Стикер из-под края, старая строка и стрелка удалены |
| UI-02 | 360 dp, 19.5:9, 200% шрифта, TalkBack, системные панели | Нет недоступных полей или кнопок. В порядке фокуса понятны стикер, блоки, перемотка, изменение порядка и переходы |
| H-01 | Порядок состоит из черновика, опубликованных Б и А | Послание и стикер открывают Б. Перенос А перед Б меняет текущую на А после подтверждения. Номера неизменны |
| H-02 | Пустой каталог, затем первый запуск без сети | Пустое состояние и состояние без данных различаются. Стикер открывает журнал в обоих случаях. Послание скрыто |
| J-01 | Читатель открывает журнал и попытку прямого авторского перехода | Доступ только к опубликованным записям. Авторские команды отсутствуют. Удалённая запись не открывается после синхронизации |
| J-02 | Автор меняет порядок, использует фильтр и сортировку по дате | Порядок меняется только в полном ручном списке. Номера и даты сохранены после перезапуска |
| J-03 | Отмена и подтверждение удаления черновика, затем публикации | Отмена сохраняет все данные. Подтверждение меняет только выбранную запись. При удалении публикации синхронизируется tombstone |
| E-01 | Создать черновик, заполнить, добавить текст, изображение и аудио, перезапустить | Поля, порядок, переносы и локальные вложения сохраняются. Читатель черновик не видит |
| E-02 | Отменить замену, затем подменить расширение у видео | Старое вложение остаётся. Видео отклоняется до сохранения. Нет пункта добавления видео |
| E-03 | Сбой записи при импорте/автосохранении и повтор | Публичный снимок и старые вложения работают. Автор видит ошибку и может повторить, содержимое редактора доступно |
| E-04 | Открыть предпросмотр, изменить масштаб и вернуться | Пагинация использует общий рендерер. Фокус/позиция редактора восстанавливаются. Предпросмотр не публикует |
| E-05 | Ввести многострочное короткое послание, затем добавить текст сверх видимой высоты | Поле растёт по вводу до настраиваемого предела, после него прокручивается. Курсор и текст доступны. Предел оценивается на телефоне, четырёхстрочный ориентир не обрезает данные |
| P-01 | Текст с абзацами, длинным словом, эмодзи, смешанными переносами | При объединении всех фрагментов получается исходный текст. Нет пропусков, дублей, пустых циклов или разорванных графем |
| P-02 | Изображение и аудио на границе страницы | Оба блока целые. Изображение вписывается с сохранением пропорций. Плейсхолдер занимает тот же слот |
| P-03 | 50+ страниц, изменение ширины и шрифта | Нумерация верна, навигация не переполняет, последняя доступна. После репагинации читается прежний смысловой якорь |
| P-04 | Листание с первой до последней и назад | На странице 2 из 3 обе кнопки активны и мягко-зелёные. На первой «Предыдущая» серая и отключена, на последней «Следующая» серая и отключена. При одной странице отключены обе. Свайп внутри seek bar перематывает |
| A-01 | Запуск, пауза, seek, конец, повтор | Состояние и таймер соответствуют аудио. Повтор с начала. Соседний блок не играет параллельно |
| A-02 | Уйти со страницы, выйти из дневника, свернуть приложение, снять наушники | Нет самопроизвольного продолжения. Подписки освобождаются при выходе. Плеер сессии соблюдает аудиофокус |
| A-03 | Медиа из кэша, медиа без кэша, битый файл | Кэш играет офлайн. Отсутствующий файл не блокирует чтение и даёт повтор. Ошибка не рушит каталог |
| S-01 | Изменить опубликованную запись и прервать загрузку вложения | Читатель продолжает видеть прежнюю редакцию. Черновик сохраняется. Повтор не создаёт дубликат |
| S-02 | Два автора или устройства правят одну ревизию, ответ теряется | Конфликт виден. Повтор с тем же ключом не публикует дважды. Незавершённые версии не появляются в каталоге |
| S-03 | Удаление, повтор старой страницы каталога, конфликт ревизий | Удалённая запись не воскресает. Неконсистентный снимок перечитывается. Рабочий кэш удерживается до валидного обновления |
| S-04 | Сервер возвращает HTML входа, 403, 404, таймаут | Состояния различаются. Каталог и черновики не затираются. В отчёте указан фактически протестированный транспорт |
| S-05 | Проверить Flutter-релиз и права на облачные операции | Публичные данные исключают черновики и приватные пути. Авторские операции требуют серверной авторизации. В APK и git нет секретов |
| R-01 | Обновить сборку с существующими данными | Личные записи, сессии, аудио, история и шаблоны сохраняются. Сценарий настройки паузы работает как прежде |

## Подтверждение готовности

- Автоматизировать пагинацию, навигацию, роли, локальную транзакцию, DTO и сценарии ошибок, где они воспроизводимы. UI дополнительно проверить на Android.
- Выполнить `flutter analyze`, `flutter test`, `flutter build apk --debug`. Зафиксировать точные результаты, ветку, коммиты, изменённые файлы и путь к APK.
- Приложить скриншоты редактора, страницы 1, страниц 2 и 3, журнала обоих режимов и главной. Показать запись короткого прогона со сменой порядка, предпросмотром, листанием и перемоткой. Разделить тесты с локальным имитатором и фактическим облачным адаптером.
