# A. ЦЕЛЬ И АРХИТЕКТУРА ПРОДУКТА

Приложение — **локальный конструктор и плеер модульных сеансов автогипноза с аудиозаписями**, включая голос Сульфи, созданный отдельно в Suno. Пользователь выбирает и переставляет аудио, выставляет задержку **перед каждым** блоком, добавляет тишину/самостоятельную работу и свои голосовые записи, запускает сессию и получает её фактическую историю. Для текущего MVP НЕ интегрировать GPT, Suno API, Suno Speech Beta, облачный аккаунт и удалённую обработку личных записей.

**Три центральные сущности, которые нельзя смешивать:**

1. **Сохранённый шаблон (`SessionTemplate`)** — многократно используемый образец последовательности и настроек, с ID, названием, описанием, категориями/группами, исходным составом и длительностями. Изменяется только явным действием пользователя.
2. **Текущая конфигурация (`CurrentSessionDraft`)** — ОДНА автоматически сохраняемая рабочая копия плана будущей сессии. При запуске приложения восстанавливается последняя настройка. Если её нет — создаётся из выбранного базового шаблона при наличии файлов. Она может быть изменена без изменения шаблона. У неё есть ID исходного шаблона, флаг `modified`, поля темы/заметок и список блоков.
3. **Запущенная сессия (`SessionRun`)** — неизменяемый снимок конфигурации, который создаётся **только после нажатия «Начать сессию»**. Отдельно хранит фактические события выполнения, начало/окончание, результаты и статус. Последующие изменения шаблона и текущей конфигурации не переписывают прошлую историю.

**Не путать текущую конфигурацию с разовым/временным шаблоном.** Название для пользователя — «Текущая конфигурация». Когда она отличается от исходного шаблона — пометка **«Изменён»**. Слов «быстрая сессия» и «настройки сессии» как отдельных главных разделов НЕ использовать.

## A1. Навигационная схема

```
Главная / Рабочий планшет
 ├─ Структура сессии (полноэкранный редактор)
 │    ├─ Выбор/добавление аудио из библиотеки
 │    ├─ Редактор паузы (золотые часы) → предпрослушивание соседних треков
 │    ├─ Записать свой аудиомодуль → Диктофон → сохранить → добавить в структуру
 │    ├─ Выбор другого шаблона
 │    ├─ Вернуть из шаблона
 │    ├─ Сохранить как шаблон
 │    └─ Применить и вернуться → Главная
 ├─ Карточка активного шаблона → Выбор шаблона / управление шаблонами
 ├─ Записать свой аудиомодуль → Диктофон
 ├─ Библиотека (Общие / Установки / Мои аудиозаписи)
 ├─ Шаблоны (список, создать, переименовать, удалить, сделать базовым)
 ├─ История сессий → Карточка состоявшейся сессии → Сделать шаблон
 └─ Начать сессию → Экран проведения сессии → завершить/прервать/выход
```

На главном планшете **один**, не дублирующийся ряд доступа к библиотеке, созданию своих аудио, шаблонам и истории. Выбранный графический макет допускает эти действия как кнопки внутри планшета; НЕ накладывать вторую системную навигационную панель с теми же пунктами. Из всех полноэкранных редакторов — понятная кнопка «Назад».

# B. ГЛАВНАЯ — РАБОЧИЙ ПЛАНШЕТ СУЛЬФИ

**Внешний вид:** верхние примерно 15–20% экрана — фотореалистичные золотые глаза Сульфи над очками, полуулыбка и тёмный фон; ниже почти чёрный кожаный планшет, металлический зажим, перо/ручка, неоновая фуксия, кислотно-зелёные/жёлтые акценты. Крупные основные действия. Отказаться от декоративных афоризмов, лишних картинок внизу и дублирования навигации. Декоративное изображение не содержит неинтерактивных надписей времени/сеанса.

**Содержание планшета сверху вниз:**
- **СЛЕВА** — компактная «Структура сессии»: последовательность, у каждой дорожки **пауза ДО запуска**, затем название и отдельно длительность трека. При большом числе блоков — первые 3–5 строк, количество остальных и действие «Развернуть». Касание карточки → полноэкранный редактор.
- **СПРАВА** — «Карточка сессии»: предварительный следующий номер (не резервировать в БД до старта), текущая дата, **живые часы телефона до старта**, поле «Тема/запрос» (вручную), расчётная общая длительность, необязательные заметки. После фактического старта время начала фиксируется; история создаётся только тогда.
- **Ниже** — крупная карточка «Активный шаблон»: название, описание, краткий состав, статус «Изменён» (если настройки рабочей копии отличаются), стрелка для выбора/управления шаблонами.
- Большая основная кнопка **«Начать сессию»** или «Начать погружение» (выбрать один термин и последовательно использовать его; предпочтительно «Начать сессию» в техническом UI). Исполняет именно **текущую конфигурацию**, а не неизменённый шаблон. Первой запускается **пауза перед первым блоком**.
- **Один** нижний ряд навигационных действий: «Библиотека», «Записать свой аудиомодуль», «Шаблоны», «История». Можно выделить «Записать» более широкой/яркой кнопкой; отдельную «Быструю сессию» НЕ добавлять.

## B1. Карта кнопок главной
| Элемент | Нажатие | Что изменяется / что открывается |
|---|---|---|
| Структура сессии / Развернуть | Открыть подробный список | Редактор редактирует текущую конфигурацию, не шаблон |
| Каждая пауза в структуре, если активна | Открыть золотые часы | Пока не нажато «Применить», значение в конфигурации не изменять |
| Поле «Тема/запрос» | Редактировать тему | Автосохранение в `CurrentSessionDraft`, но не запись в истории |
| Поле «Заметки» | Ввести примечание | Сохранять в черновике; при старте копировать в `SessionRun` |
| Карточка «Активный шаблон» / стрелка | Показать список шаблонов | При выборе загрузить копию выбранного шаблона с защитой текущих правок |
| «Начать сессию» | Проверить данные, затем запустить | Создать `SessionRun`, присвоить реальный номер/время, начать задержку перед блоком №1 |
| «Библиотека» | Открыть библиотеку | Не меняет текущую конфигурацию сама по себе |
| «Записать свой аудиомодуль» | Открыть диктофон | Запись создаётся только после сохранения; может быть прикреплена к текущей конфигурации |
| «Шаблоны» | Открыть список | Новый/выбрать/переименовать/скопировать/удалить; не перезаписывать молча рабочую копию |
| «История» | Открыть журнал | Показать состоявшиеся и прерванные сессии |

**Первый запуск:** если шаблон/аудио уже доступны — подгрузить базовый шаблон как текущую конфигурацию, так что кнопка запуска готова к нажатию. Если файлы отсутствуют, не притворяться, что сессия работает: указать, чего не хватает, предложить импорт/создание. В последующие запуски восстановить последнюю изменённую рабочую конфигурацию, а не автоматически перетирать её «последней завершённой сессией».

# C. РЕДАКТОР «СТРУКТУРА СЕССИИ»

**Вид:** полноэкранный рабочий кожаный планшет **без лица Сульфи**, максимум места под техническую информацию; скролл для 20–30+ дорожек; секции можно сворачивать. Круглые часы здесь не показывать, они открываются отдельно. Не увеличивать высоту каждой строки ради декоративных эффектов.

**Верхний блок**: «Назад», заголовок «Структура сессии», текущий исходный шаблон, статус «Изменён», сводка: количество дорожек/блоков, сумма всех пауз, сумма аудио, сумма блоков самостоятельной работы, итоговое время. Числа реальные, динамические.

**Группы этапов:** предлагаемый порядок «Подготовка и вход» → «Основная работа» → «Прогрессия и установки» → «Выход». Это визуальная группировка, не жёстко зашитая структура. Каталог общих аудиомодулей дополнительно поддерживает категории: вступление, индукция, углубление, работа, интеграция, выход; библиотека установок — тематические теги. У каждого трека есть возможность произвольного положения в последовательности; одинаковые файлы разрешено ставить несколько раз. Не предполагать, что этапы всегда есть или следуют в фиксированном числе.

**Строка блока содержит:**
1. «ручку» для перемещения / номер в последовательности;
2. заметное время **паузы ПЕРЕД данным блоком**, например `00:30` (нажатие → золотые часы);
3. `▶` предпрослушивание аудио (для аудиоблока);
4. название (например, «Индукция 1.1»), краткую аннотацию/тип;
5. **длительность самого трека**, например `01:54` (отдельно от паузы);
6. меню `⋯` и/или карандаш для действий.

Для служебных блоков вместо длительности аудио показывать заданную длительность/режим. Предусмотреть хотя бы: `AudioTrack`, `SilentPause`, `FreeWork`, `VoiceRecording` (см. раздел H). Каждый блок (включая первый) имеет `delayBeforeSeconds` независимо от длительности блока. Время точностью до 5 сек для настройки паузы; внутренний движок хранит целые секунды.

## C1. Кнопки и жесты структуры
| Элемент | Поведение |
|---|---|
| «Назад» | Вернуть на главную, не терять уже подтверждённые изменения текущей конфигурации |
| Название текущего шаблона / ▼ | Список шаблонов и переключение с предупреждением о текущих изменениях |
| Заголовок группы / шеврон | Свернуть/развернуть группу без изменения порядка исполнения |
| `00:30` с иконкой часов | Открыть редактор паузы, привязанный к конкретному экземпляру блока (не только к файлу) |
| `▶` в строке | Предпрослушать именно указанный файл; не создавать `SessionRun` |
| Перетаскивание/режим порядка | Изменить порядок блоков; пересчитать номера/суммы. Пауза «едет» вместе со своим блоком |
| `⋯` у блока | Предпрослушать / заменить трек / дублировать / удалить / редактировать аннотацию при необходимости |
| «Добавить трек» | Открыть выбор из библиотеки по категориям и с поиском по названию/теме/описанию, вставить в выбранное место |
| «Добавить блок» | Выбрать служебный блок (тишина, самостоятельная работа, запись речи и т.п.) и задать длительность |
| «Изменить порядок» | Войти в удобный режим перестановки; альтернатива drag-and-drop для небольших экранов |
| «Выбрать другой шаблон» | Открыть выбор, не уничтожая незаписанные правки без подтверждения |
| «Библиотека» | Открыть каталог в режиме вставки/замены, вернуть выбранный элемент в структуру |
| «Записать свой аудиомодуль» | Открыть диктофон и по сохранении предложить «Добавить в текущую структуру» |
| «Вернуть из шаблона» | Подтверждение; заменить рабочую последовательность значениями исходного шаблона, **НЕ** изменять шаблон; тема/личные заметки не должны теряться без предупреждения |
| «Сохранить как шаблон» | Диалог названия + описания; создать новый `SessionTemplate` из текущего состава, не заменять источник без отдельного явного действия |
| «Применить и вернуться» | Зафиксировать текущие изменения `CurrentSessionDraft` и открыть главную; **не** создавать историю и **не** запускать воспроизведение |

**Внизу ровно две нужные строки управления**, как на утверждённом изображении:
1. «Выбрать другой шаблон» · «Библиотека» · яркая «Записать свой аудиомодуль».
2. «Вернуть из шаблона» · «Сохранить как шаблон» · зелёная «Применить и вернуться».

Удалить «Автозаполнение», «Список/Схема», отдельную нижнюю строку «Режим пауз» и лишние дублирующие меню. На узких экранах нижние кнопки можно разместить в компактной фиксированной панели с вертикальным скроллом контента; доступность важнее пиксельного совпадения с референсом.

# D. НАСТРОЙКА ПАУЗЫ: ЗОЛОТЫЕ ЧАСЫ

**Назначение:** изменить `delayBeforeSeconds` **перед конкретным блоком N**, увидеть, как изменение сказывается на времени группы и всей сессии, при необходимости прослушать соседние аудио.

**Внешний вид:** большие настоящие круглые золотые карманные часы на цепочке, открытая вниз передняя крышка с орнаментом, золотисто-жёлтый глаз с вертикальным зрачком внутри, тёмный фон, фуксиевый неон. Не сжимать часы по горизонтали/вертикали; сохранить круг. Если экран короткий — вертикальная прокрутка вниз до кнопок и мини-плеера.

**Управление:**
- **Левая выпуклая боковая крутилка-полусфера** — МИНУТЫ; независимый поворот/свайп, целые минуты.
- **Правая выпуклая боковая крутилка-полусфера** — СЕКУНДЫ; независимый поворот/свайп, шаг **5 секунд**, значения `00,05,...,55`. Поворот правой не должен незаметно изменять минуты.
- По каждому шагу — тихая тактильная вибрация/haptic click (если доступно и разрешено настройками устройства).
- Центральное цифровое табло `MM:SS` обновляется немедленно.
- **Ручной ввод** минут и секунд — обязательно; открыть клавиатуру нажатием по цифровому табло либо отдельной компактной иконкой. Секунды проверять/нормализовать к шагу 5 с понятным правилом (проектное предложение: предложить ближайшее кратное 5, показывая результат до применения).
- «Обнулить» ставит **только данную паузу** в `00:00`. Не обнуляет остальные паузы и не стирает шаблон.

**Контекст под часами:** `Шаблон: ...`, `Раздел: ...`, `Пауза перед треком: № и название`. Далее динамическая сводка: длительность самого трека, время раздела (с уже учтёнными задержками), суммарное время всего плана. При повороте видно новую сумму и **дельту относительно исходного значения**, не добавленную повторно. Не считать `MM:SS` как длительность трека.

## D1. Кнопки золотых часов
| Кнопка | Поведение |
|---|---|
| `×` | Закрыть редактор; если значение не применено — отбросить только локальную правку (с подтверждением при необходимости) |
| Левая крутилка | Изменить минуты, не меняя секунды |
| Правая крутилка | Изменить секунды шагом 5, не меняя минуты |
| Цифровое время | Открыть ручной ввод `мин:сек` |
| «Обнулить» | Установить локальную редактируемую паузу в ноль; итог пока предварительный |
| «Прослушать предыдущий трек» | Предпрослушать ближайшую предыдущую **аудиодорожку** относительно текущей паузы (если отсутствует — недоступна с пояснением) |
| «Прослушать следующий трек» | Предпрослушать **текущую аудиодорожку**, которая зазвучит после редактируемой паузы; если блок не аудио — ближайшую следующую дорожку с явной подписью |
| Маленькая зелёная «Применить» | Записать новую задержку в текущую конфигурацию, обновить все суммы, вернуться к структуре; **не** менять исходный шаблон |

**Ниже кнопок — настоящий мини-плеер**: обложка (если есть), название воспроизводимого соседнего трека, аннотация/описание, воспроизведение/пауза, полоса прогресса с перемоткой, текущее время / длительность. При выборе другого трека предыдущий предпросмотр останавливается; при закрытии редактора плеер освобождает ресурсы. Предпрослушивание никогда не запускает сессию и не фиксирует сеанс в истории.

**Пример формулы:** `новая общая длительность = исходная общая длительность − старая задержка этого блока + новая задержка`. Для группы аналогично. Не складывать одну и ту же паузу дважды. Для открытых/неограниченных рабочих блоков показывать «расчётная длительность» с пометкой об оценке, а не ложную точность.

# E. БИБЛИОТЕКА АУДИО

**Ровно три верхнеуровневых раздела:**
1. **«Общие аудиозаписи»** — вступление, индукция (Элман и пр.), углубление, рабочие инструкции, интеграция, выход; внутри — тематические категории этапов.
2. **«Установки»** — готовые тематические записи/внушения для желаемых способов реагирования, по темам (например, уверенность, личные границы). Это **готовые аудио**; заявленный эффект не гарантируется.
3. **«Мои аудиозаписи»** — созданные пользователем личные команды, установки, фрагменты и записи с микрофона, а также импортированные личные записи по его выбору.

Поиск по всей библиотеке и фильтрация внутри раздела: название, описание, тематические метки, тип/категория. Список может содержать сотни установок; нужна производительная прокрутка/поиск. У записи есть стабильный `audioAssetId`, отображаемое название, аннотация, категория/подкатегория, теги, фактическая длительность, локальный путь, формат, источник, дата создания, версия (если введена). Один файл может входить в множество шаблонов и несколько раз в один шаблон.

**Импорт:** MP3/M4A/WAV (по возможностям выбранного аудиодекодера Android). Копировать файл в управляемое хранилище приложения, а не полагаться на временный URI системного picker. Позволять редактировать метаданные. При попытке удалить файл, используемый шаблонами, показывать зависимые шаблоны и варианты, не ломать их молча.

# F. ДИКТОФОН / СОЗДАНИЕ СВОЕГО АУДИОМОДУЛЯ

**Название CTA:** «Записать свой аудиомодуль». Это точнее, чем «Мои установки»: можно записать установку, команду, инструкцию, личную заметку или другой фрагмент.

**Экран:** крупный статус записи, таймер, индикатор уровня звука (если технически доступен), `Запись`, `Пауза`, `Продолжить`, `Завершить`, `Прослушать`, `Перезаписать/Удалить`, поля `Название`, `Описание`, категория/теги, `Сохранить`. При отмене несохранённой записи спросить подтверждение. После сохранения в локальную библиотеку — предложить `Добавить в текущую структуру`.

**Название по умолчанию:**
- если запись создана **в реально запущенной сессии**, например `Сессия №118 · 14:26 · Личные границы`, связать сохранённый файл с `SessionRun` по ID;
- если запись создана **до запуска**, дать временное имя вроде `Личная запись · 02.11.2026 14:26 · [тема из текущей конфигурации]`, но **НЕ создавать историю и НЕ назначать окончательный номер**;
- если тема пустая, использовать дату/время или порядковый номер записи.

Название и описание всегда доступны для ручной корректировки до сохранения и позже в библиотеке. Сама запись остаётся пригодной для использования в любых других сессиях независимо от первоначальной связи.

**Различать три разных процесса:**
1. запись **нового аудиомодуля для библиотеки**;
2. запись **темы/запроса текущей сессии** (если предусмотрена как голосовое вложение);
3. запись **голоса во время самостоятельной работы внутри сессии**.
Не смешивать их в одну таблицу без указания типа и принадлежности. Реализовать в MVP основной диктофон; запись во время сессии вводить как отдельный проверяемый функциональный блок.

# G. ШАБЛОНЫ: СОХРАНЕНИЕ И ПЕРЕКЛЮЧЕНИЕ

**Экран «Шаблоны»:** каталог сохранённых шаблонов с поиском/описанием/общей длительностью/количеством блоков. Кнопки «Создать шаблон», «Выбрать», «Сделать шаблоном по умолчанию» (если поддержано), «Копировать», «Переименовать», «Удалить» и «Создать из текущей конфигурации».

**Главный принцип:** выбор шаблона создаёт/загружает **копию** для текущей конфигурации, исходный шаблон не меняется при ежедневном редактировании. Текущая конфигурация может быть сохранена как **новый** шаблон; перезапись существующего — только отдельная явная команда с подтверждением. Из истории сессий также можно создать шаблон на основе сохранённого снимка её состава/таймингов.

### G1. Сценарии переключения
- Если текущая конфигурация не изменена, выбор другого шаблона заменяет её настройки; тема/заметки обрабатываются явно (проектное предложение: предложить сохранить текущую тему отдельно либо оставить её в форме).
- Если текущая конфигурация **изменена**, показать выбор: «Сохранить как шаблон», «Переключить без сохранения текущих настроек» или «Отмена». Нельзя сбрасывать молча.
- «Вернуть из шаблона» восстанавливает блоки, порядок и задержки исходного шаблона; если тема или заметка будут затронуты — отдельно предупредить/сохранить.
- Даже без нажатия «Сохранить как шаблон» последняя рабочая конфигурация автосохраняется между открытиями приложения.
- При пустой библиотеке, отсутствии исходного шаблона или переименованном/удалённом файле показать честную проблему и предложить разрешение.

# H. АУДИОДВИЖОК И ЭКРАН ПРОВЕДЕНИЯ СЕССИИ

**Последовательность всегда:** `delayBefore(block1) → block1 → delayBefore(block2) → block2 → … → завершение`. «Пауза до» — не пауза «после». Поэтому задержка перед самым первым треком нужна для того, чтобы пользователь успел лечь и подготовиться.

**Типы блоков (MVP-предложение, соответствующее обсуждению):**
- `AudioTrack`: воспроизвести конкретный аудиофайл с известной длительностью.
- `SilentPause`: отдельная заданная тишина/ожидание нужной длительности.
- `FreeWork`: самостоятельная работа на заданное время с возможностью закончить досрочно или продлить; при разрешении может включать запись речи.
- `VoiceRecording`: записывать голос в ходе сессии определённый период либо до явной остановки (особенности аудиофокуса Android проверить отдельно).

Каждый блок имеет отдельное `delayBeforeSeconds`, параметры содержания, стабильно привязанный идентификатор, порядок и группу. В графическом списке сессии это показывается ясно. Если тип длительности не фиксирован, суммарное время — расчётная оценка с пометкой.

**Кнопки экрана проведения:**
| Элемент | Что делает |
|---|---|
| Пауза | Ставит на паузу очередь/отсчёт или проигрывание, сохраняет позицию |
| Продолжить | Продолжает с текущей позиции без двойного запуска блоков |
| +5 минут / Продлить рабочий этап | Доступно на этапе самостоятельной работы; корректно обновляет план исполнения (но не обязательно исходный шаблон) |
| «Завершить работу» | На блоке самостоятельной работы — перейти к следующему этапу / предусмотренной интеграции |
| «Перейти к выходу» | В любой момент перейти к настроенному модулю выхода, если файл доступен; иначе понятное безопасное завершение без ложного воспроизведения |
| «Остановить сессию» / «Прервать» | Остановить и зафиксировать `прервана`; не путать с успешным завершением |
| Завершение последнего блока | Записать `завершена` и фактическую дату/время |

**Сессия не должна исчезать из истории при аварии:** сохранять checkpoint после старта, перехода между блоками, паузы/возобновления и периодически во время длинного проигрывания. Если процесс был убит, при следующем запуске разрешить восстановление/завершение с корректным статусом, но не отмечать её «успешно завершённой» автоматически.

**Воспроизведение при блокировке экрана:** использовать поддерживаемый Android/Flutter foreground/background audio механизм, медиасессию и корректные permission/notification (по версии Android). Не утверждать, что фоновой режим работает, без реального теста. Не использовать гаджеты как обязательное условие работы.

**Осторожность:** предусмотренный блок выхода и доступная пользователю остановка — обязательные. Автоматические направленные регрессии к травматическим «воспоминаниям» не добавлять по умолчанию; темы и установки пользователь выбирает добровольно.

# I. ИСТОРИЯ СЕССИЙ И ЖУРНАЛ

**Журнал создаёт записи только при старте воспроизведения**. Слева на главной до старта можно показывать предварительный следующий номер, но не создавать `SessionRun` на одно открытие приложения. Порядковый номер назначать атомарно при фактическом старте, без повторений. Дату и время хранить как timestamp, показывать в локальном времени устройства.

**Поля карточки истории:** ID/номер, название темы, произвольная заметка, фактические начало и окончание, длительность, базовый шаблон и версия, полный снимок последовательности с настройками, статус (`в процессе`, `завершена`, `прервана`, при необходимости `ошибка`), где закончилась сессия, список сыгранных/пропущенных блоков с фактическими временными отметками, длительность прослушанного по каждому, привязанные голосовые записи.

**Кнопки истории:**
- тап по записи → подробная карточка и журнал исполнения;
- просмотреть последовательность фактически использованных блоков;
- открыть/прослушать созданные в сессии записи (если пользователь разрешил запись);
- **«Создать шаблон из этой сессии»** → создать новый шаблон из снимка конфигурации, не меняя оригинал;
- при необходимости удалить запись истории по подтверждению, отдельно от удаления личных аудиофайлов.

**При прерывании** записать точное время, блок, состояние ожидания/проигрывания, достигнутый прогресс и что НЕ успело воспроизвестись. Никакой выдуманной информации о терапевтическом результате — только реально зафиксированные технические данные и пользовательские заметки.

# K. КОНТРОЛЬНЫЕ ПОЛЬЗОВАТЕЛЬСКИЕ СЦЕНАРИИ

**K1. Быстро начать.** На первом экране есть активная рабочая конфигурация → нажать «Начать сессию» → фиксируется номер/старт, начинается заданное ожидание перед первым треком, затем воспроизведение → журнал содержит фактический результат.

**K2. Внести изменения, не меняя шаблон.** Главная → «Структура» → поменять паузу 00:15 на 06:30 золотыми часами → «Применить» → «Применить и вернуться» → Главная показывает статус «Изменён» и новую расчётную длительность → закрыть/открыть приложение → рабочая конфигурация сохранилась, исходный шаблон неизменён.

**K3. Сохранить новую конфигурацию.** Изменить треки/паузы → «Сохранить как шаблон» → ввести название/описание → новый шаблон появляется в списке; старый не перезаписан.

**K4. Переключить шаблон.** Изменённый черновик → выбрать другой шаблон → предупреждение, можно сохранить, отменить или переключиться осознанно → никакой молчаливой потери изменений.

**K5. Создать свой трек.** Главная/Структура → «Записать свой аудиомодуль» → записать, пауза, продолжить, завершить, прослушать, назвать, добавить описание, сохранить → трек появляется в «Мои аудиозаписи» → доступно добавить в структуру.

**K6. Настроить паузу между двумя аудио.** Из структуры тап `00:30` перед треком N → часы показывают шаблон/раздел/трек → прокрутить левую и правую крутилки → меняются только соответствующие величины → видна дельта общей длительности → прослушать N−1 / N в мини-плеере → «Обнулить»/«Применить» → изменение только в черновике.

**K7. Двадцать дорожек.** Список 20–30 элементов быстро прокручивается, группы сворачиваются, строки читаемы, можно переместить повторяющуюся дорожку вместе с привязанной паузой.

**K8. Прерванная сессия.** Начать сессию, пройти несколько треков, прервать в середине другого → история содержит статус «Прервана», время, точный блок и фактический прогресс; доступно «Создать шаблон» на основе замороженной структуры.

**K9. Нет файла.** Если модуль в конфигурации ссылается на отсутствующий медиафайл, показать его и предложить заменить/импортировать; не стартовать очередь молча.

**K10. Предпрослушивание не является сессией.** Прослушивание любого трека в библиотеке, структуре или таймере не создаёт историю, номер сеанса и не изменяет тайминги.

# L. ПЛАН ПОЭТАПНОЙ РАЗРАБОТКИ И ПРИЁМКА

1. **Аудит существующего кода.** Зафиксировать, какие экраны и функции реально уже работают, какие отсутствуют. Не удалить работающее. Если что-то невозможно в окружении Codex (например, Android SDK), честно обозначить ограничение.
2. **Модели и хранилище.** Реализовать три отдельные сущности, снимки данных, черновик, сохранение, список записей и шаблонов; при необходимости миграция старого локального формата без потери существующих аудио.
3. **Библиотека и импорт.** Три раздела, метаданные, поиск, импорт и стабильные локальные ссылки.
4. **Структура и шаблоны.** 20+ строк, группировка, reorder, добавление/замена/удаление, сохранение, восстановление.
