# Как запустить разработку «Сульфи — гипнотерапевт»

1. Создай приватный репозиторий `sulfi-hypnotherapy` на GitHub. Инициализируй с README. Для .gitignore выбери Flutter, если доступен; лицензия: No license.
2. Распакуй ZIP и загрузи файлы **из папки** `sulfi_app_starter/` в **корень** репозитория: `README.md`, `SPEC.md`, `AGENTS.md`, `BACKLOG.md`, `VERSIONING.md`, `PROMPT_RU.txt`, `START_HERE_RU.md` (замени созданный пустой README). Не загружай приватные аудио и записи.
3. После загрузки открой выпадающий список веток в Code; создай ветку `develop` от `main`. Пока `main` не содержит работающего приложения, это базовая структура; впоследствии в `main` будет только проверенный код. Важно: в бесплатном тарифе GitHub для приватного репозитория защита веток правилами может быть недоступна, поэтому процесс контролирует владелец вручную.
4. Открой Codex Cloud в ChatGPT, подключи GitHub и выбери `sulfi-hypnotherapy`. Для разработки используй `develop` или ветку `feature/...`, не публикуй изменения прямо в `main`.
5. Начни новую задачу, вставь `PROMPT_RU.txt` и добавь: «Обязательно изучи VERSIONING.md. Настрой процесс версий, проверки в GitHub Actions и сохранение APK-релизов. Не публикуй релизы без моего одобрения».
6. Просматривай результат каждого этапа, проверки и PR. После подтверждённой работоспособности — объединение в `main`, создание GitHub Release с версией `vX.Y.Z` и APK.
7. Важно: резервная копия исходного кода в GitHub не равна резервной копии личных аудиозаписей и шаблонов внутри приложения. Для них необходим отдельный экспорт/резервирование.

Это техническое задание, а не готовый APK. Рабочий код, тесты и APK должен собрать Codex в подключённом окружении.
